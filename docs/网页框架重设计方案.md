## 0. 本轮新增的三项关键结论

1. **React 18 决定 3D 栈版本上限**（实测）：本仓库为 React 18，而 `@react-three/fiber@9` 要求 React 19。因此钉死 **fiber 8.18.0 + drei 9.122.0 + three 0.180.0 + @types/three 0.180.0**（最终取自仓库既有 pnpm catalog），不可按参考项目（React 19 + fiber 9）照搬。
2. **现有几何比预想更"脏"也更简单**（实测，详见 §4.2；数值由 `src/lib/geo3d/__tests__/geometry.test.ts` 固化为回归契约）：34 条省域路径共 **329 个子路径 / 3283 点**、命令集仅 `M/L/Z`；其中 **282 个零面积退化子路径**（噪声）、过滤后保留 **47 环 / 2875 点**、**仅 1 个真孔洞**（福建省）；**澳门是纯退化图形**（无有效多边形）→ 必须有"跨省降级规则"。
3. **现有 CI 预算会被 3D chunk 直接撞穿**（实测）：`tasks/check-bundle-size.mjs` 现有 `LAZY_CHUNK_BUDGET = 750KB raw / 180KB gzip`，而 three + fiber + drei 子集单独就约 200–260KB gzip。必须新增**独立的 3D chunk 预算 + manualChunks 拆分**，否则 `pnpm bundle:check` 必红。

## 1. 定位与框架（v5 结论，不变）

> **「畜种光图」**：把一份 46 页官方名录 PDF，变成一座会发光的 3D 中国——**1186 份官方核验档案里可落点的品种，各自在真实产区坐标上亮起一束光**；四个镜头看全国，三台展教装置动手玩，每一束光都能链回官方文件。
>
> **唯一受众**：好奇的人（学生/教师/公众/评审）。**唯一钩子**："1186 个地方品种，你家的省份亮了几个？"
>
> **路由（5 条）**：`/` 光图（主展项 + 四镜头 + 省份聚焦）· `/arcade` 互动厅总览 · `/arcade/:game` 三台装置子页 · `/breed/:id` 档案抽屉 · `/about` 馆史与库房；旧路由全部重定向。
>
> **赛道**：数据可视化及数据驱动作品（理由与兜底见 v5 §3，不变）。
>
> **高原**：不设章节。青海/西藏与其他省份同构，仅由数据自然高亮。

## 2. 依赖与版本（实测钉死，不可照搬参考项目）

| 包 | 版本 | 依据 |
| --- | --- | --- |
| `three` | `0.180.0` | 仓库既有 `pnpm-workspace.yaml` catalog 已固化该版本；drei 9 要求 `three >= 0.137`，fiber 8 要求 `>= 0.133` |
| `@types/three` | `0.180.0` | 与 three 主版本对齐；并在 `pnpm-workspace.yaml` 加 override，抵消 `stats-gl → three-mesh-bvh` 带入的 0.163 版本（否则出现 `boundingBox`/模块增强类型冲突） |
| `@react-three/fiber` | `8.18.0` | **实测 peer: `react >=18 <19`** —— 本仓库 React 18，fiber 9（需 React 19）不可用 |
| `@react-three/drei` | `9.122.0` | 实测 peer: `@react-three/fiber ^8` + `react ^18` —— 与 fiber 8 匹配 |

**明确不引入的依赖**（逐条有理由）：
- `@react-three/postprocessing`（Bloom 等）：后处理会显著提高 GPU 成本与设备兼容风险；本方案的"发光"用**自发光材质 + 加性混合贴片**实现，零后处理。
- `gsap`：相机缓动改成 `useFrame` 内的自带 lerp（约 20 行），不新增依赖。
- `zustand`：场景状态（选中省、镜头、抽屉）用现有 React Context/`useState` 管理；fiber 内部自带的 zustand 不需要我们再加一份。
- `d3-geo`：参考项目用它做墨卡托投影，但我们**已有 `projectCoordinate(lon, lat)`**（`src/data/chinaMap.ts`，实测：经度 73–135 → x 0–1000，纬度 54–18 → y 0–800），直接复用，零新依赖。

**尺寸预算（必须改 `tasks/check-bundle-size.mjs`）**：

| 预算项 | 现值 | 处置 |
| --- | --- | --- |
| `ENTRY_BUDGET` | 650KB raw / 220KB gzip | **不动**（3D 全部懒加载，入口不得引入 three） |
| `AGGREGATE_BUDGET` | 1100KB raw / 320KB gzip | **不动**（静态图不含 3D chunk） |
| `CSS_BUDGET` | 90KB raw / 16KB gzip | **不动** |
| `LAZY_CHUNK_BUDGET` | 750KB raw / 180KB gzip | **保留给数据/页面 chunk**；新增 `THREE_CHUNK_BUDGET = 1400KB raw / 340KB gzip` 单列 3D chunk，并在脚本里把匹配 `three-vendor`/`r3f-*` 名称的 chunk 从通用懒加载预算中排除 |
| `manualChunks` | — | 新增规则：`three` + `@react-three/*` 全部归入独立 `three-vendor` chunk（缓存友好 + 预算可分离） |

## 3. GitHub 参考实现调研与取舍

**主要参考**：`dora-ljh/china-map-3d`（MIT，玻璃质感 3D 中国地图，React 19 + fiber 9 + three 0.171 + drei + gsap，可下钻）——本轮已逐文件读其源码（`src/graph/lib/geo.ts`、`src/viz/MapLayers.tsx`、`src/viz/Flylines.tsx`、`src/viz/Markers.tsx`、`src/viz/Labels.tsx`、`src/viz/MapScene.tsx`、`src/constants/mapConfig.ts`、`src/hooks/useViewport.ts`）。辅助参考：`vasturiano/r3f-globe`（r3f 三维球体数据可视化，点/柱/弧的实例化写法）、`pengpen1/three-china-map`（省域挤出与飞线的最小实现）。

| 参考做法 | 我们的取舍 | 理由 |
| --- | --- | --- |
| **局部坐标系约定**：XY 为地图平面、+Z 为高度，外层 group 统一 `rotation = [-π/2, 0, 0]` | **照搬（概念层面，自研代码）** | 各图层（省块/光柱/飞线）只要守住"XY 平、Z 高"就自动对齐，是这类场景最不易出错的约定 |
| `ExtrudeGeometry` + `Shape`/`Path` 组装（含 holes） | **照搬概念，但用我们自己的 SVG 路径解析**（§4） | 参考项目吃 GeoJSON；我们的数据是 SVG path（M/L/Z），需要自建解析 + 噪声过滤 |
| 基础层用 **matcap 金属材质**、中层用 `MeshTransmissionMaterial` 玻璃体 | **只用 matcap/标准材质；放弃玻璃体** | 透射材质渲染成本高、移动端风险大；我们的主视觉是"光"而非"玻璃" |
| drei `<Edges>` 做省份描边、`<Html>` 做标签、`QuadraticBezierLine` 做飞线（dashOffset 流动） | **Edges / Html 照用；飞线改为"光柱 + 连线"**（仅玩法需要时出现在"对照"视图） | 主视觉是 1062 根光柱，飞线只在档案对照等局部场景使用，避免视觉噪声 |
| `CameraRig`：进场时相机从 1.7 倍距离 `power3.out` 推入，期间禁用 OrbitControls | **照搬交互设计，改实现**（`useFrame` lerp，1.4s，`easeInOutCubic`；reduced-motion 直接到位） | 进场推镜是"博物馆感"的关键；不引入 gsap |
| `useViewport` 把 DPR 锁在 2 | **照搬** | 4K 屏下是数量级的像素成本差异 |
| 用 `seededValue(adcode)` 生成演示数据 | **不采用（红线）** | 我们是数据可视化作品，**任何视觉元素必须来自已核验字段**，禁止程序化伪造数值（§5 诚实映射） |
| 用 `Environment`（HDR 环境贴图）+ Bloom 做电影感 | **不采用** | HDR 贴图是额外资产体积；Bloom 需后处理；改用"暗厅 + 雾 + 加性发光 + 星尘粒子"营造氛围 |

**许可证合规**：参考项目为 MIT。我们不复制其源码文件，只吸收公开的工程做法（坐标约定、预算纪律、交互设计），并在 `/about` 的第三方资源清单中注明参考项目与许可。

## 4. 3D 场景精细规格

### 4.1 坐标系与投影（三层共用一套）

```
local:  XY = 地图平面（+Y 朝北），Z = 高度
group:  rotation = [-π/2, 0, 0]  →  本地 +Z 抬成世界 +Y
投影:   project3D(lon, lat) = [ (x - 500) / 100, -(y - 400) / 100, 0 ]
        其中 (x, y) = projectCoordinate(lon, lat)   // 复用现有函数
        结果域：约 X ∈ [-4.3, 4.3], Y ∈ [-3.6, 3.6]（与相机参数配套）
```

- 所有图层（省块、光柱、星尘、飞线）都在 local 下构建，**禁止**任何图层自带旋转；
- `project3D` 是唯一投影入口，2D 降级路径复用同一个 `projectCoordinate`，保证 2D/3D 位置一致。

### 4.2 省域几何：解析、噪声过滤、孔洞、退化保护（本轮实测）

| 实测事实 | 规格动作 |
| --- | --- |
| 34 条路径，命令集仅 `M/L/Z`，合计 3064 点、最大子路径 241 点 | 写一个约 60 行的解析器：按 `M` 切子路径 → 提取点对 → 去重相邻点 → 闭合 |
| **63 个子路径面积为 0**（三点共线等噪声，遍布 10 个省） | **面积过滤 `EPS = 0.5`**：过滤后保留 **47 个环、2875 点**（实测），噪声全部消失 |
| **仅 1 个真孔洞**：福建省第 3 子路径（4 点，面积 2.11），其质心落在同省主环内 | 孔洞判定用**质心 point-in-polygon**（勿用 bbox 包含，实测 bbox 会产生 22 个误判）；命中的环转成 `Path` 作为 `Shape.holes` |
| **澳门为纯退化图形**（两条子路径均零面积） | **跨省降级规则**：过滤后无有效环的省 → 不生成省块，改在该省名义坐标处放一个直径 0.06 的**发光圆点 + 常驻文字标签**（保证"34 个行政区一个不缺"，且不伪造几何） |
| 挤出高度需要分级 | `ExtrudeGeometry({ depth, bevelEnabled: false, curveSegments: 1 })`；depth 由该省馆藏量四级映射：`0 → 0.05`（基座）、`1–20 → 0.12`、`21–40 → 0.20`、`>40 → 0.30` |
| 选中的省要"抬起来" | 不给 geometry 加动画（贵），改为**整块 group 的 `position.z` 缓动 +0.18**（1.2s easeInOutCubic） |

### 4.3 材质与灯光（无后处理方案）

| 元素 | 材质/参数 |
| --- | --- |
| 省块（34 个独立 mesh，为了可拾取） | `MeshStandardMaterial`：`color` = 深墨绿 `#16211c`，`roughness 0.9`，`metalness 0.05`，`emissive` = 该省主类别色（`categoryIcons.ts` 既有色板），`emissiveIntensity = 0.06 + 0.10 × 归一化馆藏量`；悬停时 `emissiveIntensity` 提升到 0.45、描边加亮 |
| 省块描边 | drei `<Edges>`（`color #d4a853`，`lineWidth 1`），仅悬停/选中时显示（默认隐藏，省 GPU） |
| 底座 | 一块 12×10 的平面 + `MeshBasicMaterial` 深色（`#0a0e0c`），配 drei `ContactShadows`（`opacity 0.5`，`blur 2.4`）做接地感；**不用镜面反射**（成本高、收益低） |
| 光柱核心 | `InstancedMesh`：`CylinderGeometry(0.006, 0.006, 1, 6, 1, true)` 开口圆柱 + `MeshBasicMaterial({ blending: AdditiveBlending, transparent: true, depthWrite: false })`，每实例颜色来自 `instanceColor`；柱高 = `0.10 + 0.03 × min(记录数, 8)` |
| 光柱光晕 | 单个 `THREE.Points`（与光柱同坐标），`PointsMaterial` + **程序化生成的 128×128 径向渐变纹理**（Canvas 画，零资产）+ 加性混合，`sizeAttenuation: true`；点大小按镜头距离自适应 |
| 星尘背景 | `THREE.Points` × 600（确定性随机种子固定），极低透明度加性混合，位于地图下方 Z=-0.6 |
| 灯光 | `ambientLight 0.35` + 一盏 `directionalLight(0.6)` 从 `[4, 8, 6]`；**不加载 HDR/环境贴图** |
| 雾与色调 | `scene.fog = FogExp2('#080b09', 0.055)`；渲染器 `ACESFilmicToneMapping`、`outputColorSpace = SRGBColorSpace`、`antialias: true`、`powerPreference: 'high-performance'` |

### 4.4 相机与运镜

- `PerspectiveCamera`：`fov 45`，初始 `position [0, 5.6, 7.4]`，`near 0.1`，`far 200`；
- `OrbitControls`：`enableDamping`，`dampingFactor 0.08`，`minDistance 3.2`，`maxDistance 14`，`maxPolarAngle 82°`，`enablePan false`（防止用户"丢地图"）；
- **进场运镜**：从目标机位 ×1.8 处沿视线推入，1.4s `easeInOutCubic`，期间 OrbitControls 禁用；reduced-motion → 直接到位；
- **镜头切换（四镜头 / 省份聚焦 / 检索飞向）**：全部走同一个 `flyTo(target, distance, duration)`，`duration ≤ 1.2s`，结束后交还控制权；
- 自动巡游：默认关闭；HUD 提供"自动巡游"开关（`autoRotate` speed 0.25），reduced-motion 下该开关隐藏。

### 4.5 拾取与交互（精细）

| 交互 | 实现 |
| --- | --- |
| 省份悬停 | `onPointerMove` 命中省 mesh → 描边显示 + 光标 `pointer` + HUD 显示省名与馆藏量；**节流到每帧最多一次**（用 `e.pointerId` 判重） |
| 省份点击 | `onClick` → `flyTo(该省中心, 4.2)` + 侧栏展开（列表虚拟滚动）+ 该省结论句；再次点击空白（`onPointerMissed`）→ 复位 |
| 光柱悬停 | 对 `InstancedMesh` 使用 R3F 事件（`e.instanceId` 可用）→ 单一 HTML 浮层显示"品种名 · 类别 · 徽章"，**不逐点建 DOM** |
| 光柱点击 | 打开档案抽屉（`/breed/:id`，pushState 而非整页跳转，Esc 返回） |
| 检索 | 输入品种名 → 匹配单条时 `flyTo(该点, 2.6)` 并高亮（临时把该实例颜色改为金色 + 放大 1.6 倍，1.5s 后复原）；多条时出候选列表 |
| 键盘 | `Tab` 依次进入：镜头切换器 → 检索框 → 省份列表（列表即"键盘等价物"）→ 抽屉；抽屉内 `Esc` 关闭；**3D 场景本身不要求可 Tab 遍历**（由列表承担等价操作） |
| 移动端 | 单指旋转、双指缩放（OrbitControls 默认）；`dpr` 上限 2；地图初始机位自动拉远 1.3 倍以适配窄屏 |

### 5.2 同坐标聚合（复用既有确定性算法）

1086 条记录中大量共享同一产区坐标。聚合规则**照搬现有 `ChinaMap.tsx` 的确定性偏移**（实测其实现：`angle = index / group.length × 2π − π/2`，`radius = min(18, 7 + group.length × 0.45)` 单位为 2D 像素）→ 3D 中除以 100：`radius = min(0.18, 0.07 + n × 0.0045)`。同一坐标的 n 条记录按角度均匀铺开，**排序键用 id（稳定）而非数组顺序**，保证每帧一致。

### 5.3 四镜头的实现规格

| 镜头 | 视觉实现 | 结论句数据源 |
| --- | --- | --- |
| 全部分布 | 全部光柱按类别色显示；省块按馆藏量发光 | `COLLECTION_SUMMARY`（1186 / 31 / 15） |
| 类别构成 | 选中类别的光柱保持原色、其余降为灰度 `#3a4640` 且透明度 0.25（**材质是一次性的两套实例化网格，切换只改 `visible`**，不做逐实例重算） | `categoryCounts`（15 类计数，从数据运行时算，不硬编码） |
| 国家级保护 | 金色实例组 `visible = true`；其余降灰 | `nationalProtectedMatches = 271` |
| 濒危之窗 | 反相：仅濒危组可见（0.8Hz 闪烁）；省块自发光降到 0.02 | `editorialEndangered = 82` |

**过渡动画**：镜头切换用统一的 `1.0s` 交叉：旧组不透明度 → 0、新组 → 1（材质 `opacity` 缓动，非逐实例）；reduced-motion 直接跳变。

## 6. 互动厅精细规格（三装置）

### 6.1 装置一 · 找家挑战（3D 交互）

| 项 | 规格 |
| --- | --- |
| 出题 | 从"已核验省份"记录中确定性抽样（种子 = 局号，可复现）；题干卡显示：品种名 + 类别 + **类别剪影图**（复用 §6.2 的 15 张 SVG） |

### 6.2 装置二 · 识图挑战（剪影 + 照片两模式）

| B · 照片认品种（增量启用） | 显示一张**已核验授权照片**（Commons，CC0/PD/CC BY/CC BY-SA，文件标题含品种名），从 4 个同类别品种中选 | 复用 `tasks/source-commons-images.mjs` 管线；**实测当前 `breedImageOverrides` 为空（已核验本地图片 0 张）**，需扩充候选（19 → 60+）并跑通下载登记；验收下限 20 张，不足则只上模式 A（不阻塞上线） |

### 6.3 装置三 · 知识问答（数据自动出题）

| 题型 | 干扰项策略 | 解析 |
| --- | --- | --- |
| "下列哪个是国家级保护品种？" | 同类别、非保护记录 | 链到 940 号公告匹配来源 |
| "「XX」属于哪个类别？" | 同类群邻近类别（如 驴/马、鸭/鹅） | 链到档案的类别字段 |
| "「XX」的产区在哪个省？" | 同类别、不同省记录 | 链到档案省份（仅用已核验省份） |
| "这个剪影对应哪一类？" | 与装置二 A 共享题库 | — |

- 生成器：`src/lib/quizGenerator.ts`，纯函数 + 确定性种子（局号），**可单测**；
- 出题前的硬断言：所有参与记录必须 `getVerificationLevel().identity === 'official' | 'editorial'`，且所用字段通过校验；否则换题；
- 每题解析必须带一个可点击的档案链接 —— 把"答题"转化为"进档案"的入口。

### 6.4 互动厅外壳（总览页 + 子页）

- **`/arcade` 是总览页**：三张装置卡（玩法 / 局数 / 数据边界 / 「进场」按钮）——一屏只做选择，不把三台装置挤在一起同时作答；
- **`/arcade/:game` 是装置子页**（`find-home` / `identify` / `quiz`）：每页只渲染一台装置，页内顶部一条切换条可自由换装置（`aria-current` 标当前项），未知 id 自动回落 `/arcade`；
- 每台一局 ≤ 3 分钟；结果卡含"档案链接"与"再来一局"；出题红线脚注在总览与子页各出现一次；
- 计时器与连对提示克制（无弹窗、无音效依赖——音效缺失不影响体验）；
- reduced-motion：无抬升/闪烁动画，仅文字与颜色变化；
- 全键盘可完成一整局（每一题都有键盘等价操作）。

## 7. 降级路径与无障碍（含实测依据）

| 场景 | 方案 |
| --- | --- |
| 无 WebGL / 低端机 | **复用仓库内 `src/components/ChinaMap.tsx`**（实测：SVG 省域图 + 键盘可达的省份按钮 + 已测过），并叠加光柱替代物（同色圆点按类别着色）；入口自动探测 `isWebGLAvailable()`，HUD 亦提供手动切换 |
| `prefers-reduced-motion` | 无进场推镜、无镜头缓动、无闪烁、无 autoRotate；`flyTo` 直接跳到目标机位；CountUp 直显终值（既有红线契约） |
| 屏幕阅读器 | "光图数据摘要"表格（省 × 类别 × 保护数 × 濒危数），DOM 常驻；场景区 `aria-hidden`；E2E 断言表格计数与场景实例数一致 |
| 对比度 | 深色底 `#0a0e0c` 上正文 ≥ 4.5:1；颜色信息一律配文字（类别名、徽章、数字） |
| 晕动 | 默认关闭 autoRotate；推镜 ≤ 1.4s；提供"关闭动效"开关（与系统设置同步） |
