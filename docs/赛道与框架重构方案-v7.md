## 0. 一页结论

1. **赛道**：报 **自主选题类 · 数字艺术与可视化设计类赛项（数据可视化方向）**，备选「智慧教育与科普创作类」。不报「乡村振兴」指定命题（理由见 §2.3）。
2. **核心手术**：**首页主视觉从 3D 光图换回 2D 光图**——不是"降级兜底"，是"升格为主展项"。3D 场景整体删除（组件、几何管线、依赖、预算、E2E 同步删），省下的工程量全部投给 2D 信息设计与卷宗内容。
3. **框架**：整站只讲三个字——**看（可视化）· 玩（交互）· 查（档案）**。首页一屏一板块、滚动即游览完；路由 5 条、导航 3 项全部不动，只换首页内部结构。
4. **内容**：只做四处精细修复（卷宗首图、互动厅卡、首页文案、雷达图回归），不新增任何大模块。
5. **排期**：D1–D9 开发，D10–D12 材料与录制，10-23 前提交。

## 1. 为什么要换主视觉（诊断结论，全部来自 2026-10-11 实测）

### 1.1 3D 光图的五个硬伤（截图 + 代码定位）

| # | 症状 | 根因（代码位置） |
| --- | --- | --- |
| 1 | 版图只占舞台约一半，四周大片死黑，构图失衡 | `LightMapScene.tsx` 的 `solveFraming` 按"包围盒 + 光束最大高"取景，斜视机位下地图视觉重心偏左上，留白无法回收 |
| 2 | 光束是 2–8px 的细针，读作"插了一地牙签"，不像光 | `clusterSites.beamRadiusFor` 半径 0.012–0.046 世界单位；加性混合在墨绿底上把 15 类颜色洗成粉白绿灰，类别分段完全不可读 |
| 3 | 省块全部同一深绿，choropleth 完全失效——"你家的省份亮了几个？"这张钩子句的承诺，地图根本没兑现 | `ProvinceLayer` 所有省共用 `palette.province`，emissive 0.22 肉眼不可辨 |
| 4 | 金环悬浮在束顶像"棒棒糖"，无省名标签、无图例，观众无法定位任何省份 | `MarkerRings` 的环半径下限 0.052 与细束比例失衡；标签方案从未实现 |
| 5 | **四镜头在 2D 模式下是死控件**：镜头 state 只传给 3D 场景（`LightMapPage.tsx:133`），2D 的 `ChinaMap` 没有 lens prop——切到平面图后点镜头只改一句文案，图形纹丝不动 | `ChinaMap.tsx` 无 lens 支持（`grep -c "lens" = 0`） |

同屏对比：2D 版（"切换平面图"）一张图同时读出**产区大小（环径=品种数）、类别构成（弧段分色）、保护身份（金环）、省份归属（形状）**，信息密度是 3D 版的数倍。用户判断"3D 还不如最初 2D"成立，且 2D 还在持续接收数据层升级（产区聚合），3D 停在概念验证阶段。

### 1.2 结构与内容问题

- **钩子句没有交互承接**："你家的省份亮了几个？"之后，用户要在一面 31 个胶囊的墙里自己找省份——最该做成"第一步动作"的事被做成了检索负担。
- **首屏 7 个竞争焦点**：钩子句 / 体量读数 / 2D-3D 切换 / 视角预设 / 操作提示 / 镜头 tabs / 侧栏（检索+省份墙+说明文）——没有主次，新访客不知道先做什么。
- **两个搜索框同屏**：顶栏全局搜索 + 侧栏"检索品种"，功能重复。
- **卷宗页首图事故**：南阳牛页首图是一张 894×671 的外链"树木照片"（百度图床，`breedImageOverrides` 之外的待核验外链），与品种无关还把正文压到折叠线以下；对一个以"数据可信"为卖点的作品，错误配图是最贵的减分项。
- **互动厅是三张纯文字卡**：已有 15 类原创剪影 SVG 资产却未用于卡片视觉；下半屏大面积空白。

## 3. 目标框架：一页三板块「看 · 玩 · 查」

v6 的"操作台"和 v7.0 初稿的"展览叙事"都收掉，换成观众零学习的平铺结构。**整站只有三个概念，每个板块一句话 + 一个主动作**：

```
看（可视化板块） → 光图：1186 条记录落在 31 个省的真实产区上，四个镜头换着看
玩（交互板块）   → 互动厅：三台装置动手玩，题目全部由已核验字段生成
查（档案板块）   → 卷宗与馆史：每条记录都能追回官方文件
```

| 路由 | 板块 | 改动级别 |
| --- | --- | --- |
| `/` | **看 · 光图**（可视化，页面主体）＋ 玩/查 的入口卡 | **重做** |
| `/arcade` · `/arcade/:game` | **玩 · 互动厅**（交互，独立页承接完整玩法） | 卡视觉微调 |
| `/breed/:id` | **查 · 卷宗** | 版式重排 + 首图治理 |
| `/about` | **查 · 馆史与库房** | 仅同步口径 |
| 8 条旧路由重定向 | 不变 | 无 |

导航 3 项与文案不动（畜种光图 / 互动厅 / 馆史与库房），"看玩查"只作为首页各板块的角标标签出现。**可视化板块在首页就是完整本体**（不是预览缩略图），交互板块首页放三张入口卡、完整玩法在 `/arcade`——两个板块都看得见、进得去。

## 4. 首页重做规格（本方案的核心）

### 4.1 页面结构（自上而下四个区块，无侧栏、无浮层选择器、无二级概念）

```
┌──────────────────────────────────────────────────────┐
│ ① 首屏（~30vh）                                        │
│    定位语一句 + 钩子句「1186 个地方品种，你家的省份      │
│    亮了几个？」+ 数字条 1186 收录 / 31 省 / 271 保护     │
│    两个按钮：看分布 ↓（锚到②） · 去互动 →（锚到③）       │
├──────────────────────────────────────────────────────┤
│ ② 看 · 数据可视化（~75vh）                              │
│    图上方：镜头 tabs ×4 ＋ 一句结论（随镜头变）           │
│    地图：choropleth 省块 + 产区环 + 省名标签 + 常驻图例   │
│    图下方：省份速览条（点省出现，一行讲完，可关闭）        │
├──────────────────────────────────────────────────────┤
│ ③ 玩 · 互动体验（三张装置卡）                            │
│    找家挑战（点省份答地理）/ 识图挑战（剪影认类别）/       │
│    知识问答（名录常识）——剪影视觉 + 玩法一句 + 进场       │
├──────────────────────────────────────────────────────┤
│ ④ 查 · 数据档案（一行区块）                              │
│    检索框（全站唯一）+ 「数据可信」一行                   │
│    （三级徽章图例 · 124 条待核验不落点 · 馆史入口）        │
└──────────────────────────────────────────────────────┘
```

删除项（对照现状）：31 省胶囊墙、侧栏检索框（并入④全站唯一检索）、2D/3D 切换、视角预设条、"拖拽旋转"操作提示、`<details>` 摘要表（移到 `/about` 静态呈现）、v7.0 的"省份叙事卡侧栏"（降为②的一行速览条）。每个区块只有**一句说明 + 一个主操作**，重点即默认路径。

### 4.2 可视化板块（②看 · 光图）规格

| 元素 | 规格 |
| --- | --- |
| 省块 choropleth | 该省可落点记录数 → 运行时分位数切 5 档单色渐变（浅档 `#e9dfc8` → 深档 `#1d3a2d`，深色主题反向）；悬停提亮 + 描边金色；**"你家的省份亮了几个"由这一层兑现** |
| 产区环 | 保留 `buildSiteClusters` 聚合与环形分弧（已验证的信息设计）；环外加 1.5px 描边（浅底白描、深底墨描）解决"彩糖感"；悬停放大 1.08 + 浮层（省名 · 条数 · 类别构成） |
| 省名标签 | 常驻 SVG `<text>` 9px 省名；面积过小的省级单位（津/沪/港澳等）以角标圆点 + 悬浮标签显示，保证 34 区一个不缺 |
| 金环（国家级保护） | 产区环外圈 2px 金色弧呼吸（1.6s），仅"国家级保护"镜头或悬停时出现，避免常驻噪声 |
| 镜头 × 4 | 全部分布=全量；类别构成=选中类别弧段保色、其余环降灰 0.25；国家级保护=有保护记录的产区点金、其余降灰；濒危之窗=编辑口径濒危产区亮橙环。**结论句与图形同步**——3D 版没做到的，这里一步到位 |
| 开场动画 | 首次进入按省份数量降序逐省点亮（每省 90ms，总时长 ≤1.4s），数字条 CountUp；`prefers-reduced-motion` 下全部直显 |
| 省份速览条 | 点省 → 该省以外 choropleth 降透明 0.35、产区环只留该省；图下出现一行速览：**「云南 · 84 个品种 · 以鸡、羊为主 · 国家级保护 12 个」**＋横向品种 chips（点击进卷宗）。再点省或 × 关闭复位 |

### 4.3 交互板块（③玩）与档案区块（④查）规格

- **三张装置卡**：每张 = 15 类剪影 SVG 组合视觉 + 玩法一句话（"给出品种卡，在地图上点出它的家乡；点错告诉你差多少公里"）+ 局数时长 + 「进场」按钮（跳 `/arcade/:game`）。首页不内嵌游戏本体，保持简洁；`/arcade` 页复用同款卡（同一组件两处渲染）。
- **④查**：一个检索框（回车/点选即进卷宗）+ 一行数据可信声明（三级徽章小图例 + "124 条产区待核验，暂不落点" + 链接 `/about`）。不再单开面板。

### 4.4 用户旅程验收（30 秒走完三个板块）

1. 首屏 5 秒知道"这是什么馆"（定位语 + 数字条）；
2. 点「看分布」→ 地图逐省点亮，找到家乡（choropleth 一眼可辨），点它 → 速览条一行讲完（5–15s）；
3. 点「去互动」→ 三选一进场玩一局，答错也有"差多少公里"的地理反馈（15–30s）；
4. 任何品种 → 卷宗 → 页脚官方来源链。全程页面只呈现"下一个动作"。

### 4.5 3D 的处置：删除，不缝合

- **删除范围**：`src/components/lightmap/`（`LightMapScene.tsx`、`useSceneCapability.ts`）、`src/lib/geo3d/` 中 3D 专属文件（`buildProvinceGeometry.ts`、`cameraFit.ts`、`layerTransform.ts`、`parseSvgPath.ts`、`ringFilter.ts`、`viewPresets.ts` 及其测试）；`clusterSites.ts` 与 `lightMapData.ts` **保留**（2D、互动厅共用，移到 `src/lib/geo/` 以名副实）。
- **依赖**：`three` / `@react-three/fiber` / `@react-three/drei` / `@types/three` 移出 `package.json` 与 pnpm catalog；`tasks/check-bundle-size.mjs` 删除 `THREE_CHUNK_BUDGET` 并收紧 `LAZY_CHUNK_BUDGET`（实测 3D chunk 504KB raw / 134KB gzip，删除后光图页只剩 SVG 渲染，预计页面包减重 ≈60% gzip）。
- **理由**：① 2D 信息密度已全面胜出（§1.1）；② 修复 3D 需要重做取景、束形、choropleth、标签四件套，工程量 ≈ 重做，且低端机风险仍在；③ 距提交 12 天，资源应花在"所有评委都会看"的页面上。
- **答辩口径同步改写**：不再讲"3D 是不是炫技"，改讲"我们把 1186 条记录做成一张所有设备都能完整打开的地图，并用测试和审计守住每一个数字"。
