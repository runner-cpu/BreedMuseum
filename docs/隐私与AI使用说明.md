# 隐私与 AI 使用说明

更新日期：2026-10-02

中国地方畜禽品种数字博物馆以静态公开资料为主体。地图、百科、看板和对比功能默认在浏览器中使用随站点发布的馆藏数据，不要求登录，也不建立用户画像。

## AI 功能会发送什么

只有在用户主动使用 AI 问答、报告、语音识别、图片识别或图片生成时，输入内容才会发送到部署方配置的第三方服务（通过 Supabase Edge Functions 转发）。文本问题可能与站内品种知识库一同发送；上传的图片或录音会以接口所需的编码发送。AI 服务未配置时，静态科普功能仍可正常使用。

## 用途、保存与删除

数据仅用于完成当前回答、识别或生成任务。项目本身不承诺第三方服务的长期保存期限，也无法替第三方作出删除保证；任务结束后浏览器不会把原始图片或录音写入项目数据库。请不要上传身份证件、面部/人物照片、联系方式、位置轨迹、未公开研究资料或其他敏感信息。

## 结果边界

AI 输出可能错误、过时或把相似品种混淆，不能替代动物防疫、育种、生产、投资或法律意见。请回到品种详情页核对来源，并把纠错依据提交到公开仓库的 Issue。

## 浏览器端设置

语言和主题偏好只尝试写入浏览器 localStorage；当浏览器禁用存储时，网站会退回内存状态，不影响静态浏览。外链图片来自历史 CDN，图片来源、作者和授权状态仍逐图待核验；站点使用 SVG 占位图避免把失败请求当成内容保证。

## 联系与纠错

请在 GitHub 仓库提交可公开核验的纠错信息：品种名称、字段、来源链接和建议修改，不要在 Issue 中粘贴个人敏感信息。
