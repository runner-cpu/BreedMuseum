## 3. 作品简介（必填，文本）

> 建议控制在 600 字以内；以下正文约 545 字（不含空白），可直接粘贴。

《中国地方畜禽品种数字博物馆》把分散在名录 PDF、普查公告与地方志中的地方畜禽遗传资源，转译为一座可浏览、可查证、可互动的数字展馆。作品收录 1186 条馆藏记录，覆盖 31 个省级行政区、15 个类别，其中 667 条带可用图片，构成访客实际浏览的展品集合。

主要功能围绕"看·查·玩"展开：地图探索以 2D SVG 中国地图为主展项，把 667 条带图记录按真实坐标聚成 202 个产区点位，省块色阶表达已核验记录量，类别筛选可与"国家级保护""濒危之窗"两组镜头叠加；品种百科支持按名称、别名、类别、省份与濒危等级检索；数据看板公开类别构成、区域分布与字段覆盖度；品种对比可并列四条记录；互动厅提供找家挑战、识图挑战与知识问答三台数据驱动装置。

创新点有三：一是以"先看见、再查证"组织叙事，用地域认同（"你家的省份亮了几个"）把公众接进专业数据；二是建立 official / editorial / pending 三级核验与数据边界说明，124 条待核验产区的记录保留在百科但从不伪造地图落点；三是把聚合、筛选与出题范围固化为纯函数和自动化测试，让视觉结论与数据口径同源。

应用价值上，作品可用于科普教育、研学与乡土文化传播，也可作为名录类公共数据可视化的可复用范式；全站静态部署，无需后端与账号，手机与低端设备均可完整访问。

## 4. 创意来源（必填，文本）

> 以下正文约 528 字（不含空白），可直接粘贴。

选题来自一次很具体的挫败感：想了解家乡养了什么畜禽，能查到的只有 46 页的名录 PDF、分散的普查公告和各县地方志。数据并不稀缺——《国家级畜禽遗传资源保护名录》（农业农村部公告第 940 号）收录 271 个品种，《国家畜禽遗传资源品种名录（2024 年版）》更进一步收录 1129 条资源——但公众几乎看不见，也串不起来。

我们判断瓶颈不是"没有数据"，而是"没有入口"。于是放弃再做一张可检索的表格，改做一张让人愿意先看见、再去查证的地图：以省域为骨、以真实产区为点，用"你家的省份亮了几个"把地域认同接上数据，让观众从好奇出发，自然走到品种、产区与保护身份。

核心创意是"证据边界可视化"。多数同类站点把权威数据、编辑推断与待核验项混在一起；我们把三级核验状态直接做进界面与视觉通道——省块色阶只映射已核验记录量，124 条省份待核验的记录保留在百科但从不落点，濒危镜头明确标注"编辑口径、非权威结论"，识图挑战只问类别、不问品种名。宁可把结论降一级，也不拿待核验的信息当答案。

形式上选择 2D SVG 而非 3D/WebGL：本项目只需要让"位置"和"证据边界"被所有设备看见，2D 能在手机、低端笔记本和教室投影上给出同一份完整信息密度，也让键盘操作与"减少动态效果"真正可用。

## 5. 运行环境（必填，文本）

> 以下正文约 523 字（不含空白），可直接粘贴。

【线上访问】无需安装。用任意现代浏览器打开 https://runner-cpu.github.io/BreedMuseum/ 即可，推荐 Chrome / Edge 111+、Firefox 113+、Safari 16.4+（需支持 CSS color-mix()、dvh 与 SVG）；桌面建议 1366×768 及以上，移动端适配 390px 宽度。无需 WebGL、独立显卡、专用外设、账号或浏览器插件。

【部署形态】纯静态站点，构建产物由 GitHub Pages 托管；无运行时后端、无数据库、无第三方在线 AI 调用，不配置任何 API Key 或环境变量即可完整浏览。

【本地运行与复现】Node.js ≥ 20（实测 Node 24.19）、pnpm ≥ 11（实测 pnpm 11.22）。依次执行：

```bash
pnpm install
pnpm dev        # 本地开发预览
pnpm build:pages # 生产构建并生成 Pages 产物
pnpm check      # 类型检查、Biome、162 项单元测试、数据审计、文档同步、构建与包体预算
pnpm check:all  # 追加 Playwright 桌面/移动双视口端到端测试
```

【硬件】开发机 4 核 CPU / 8 GB 内存即可；展示机为普通 PC、笔记本、平板或手机，无需独立显卡。
