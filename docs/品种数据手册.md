## 2. 本轮数据变更

改造前运行时共有 687 条记录，并存在 11 组重复 ID。处理结果如下：

- 合并 8 条重复或同品种变体，得到 679 条无重复基线。
- 对 3 组同音但不同品种的记录更换稳定 ID，避免错误合并。
- 对照第 940 号公告声明 23 个需补齐名称；其中青海毛驴与既有青海驴归一，因此净新增 22 条。
- 最终运行时总数为 701，ID 与品种名称均唯一。
- 公告畜禽部分 271 个名称全部能映射到站内规范名称；蜂 12 种、蚕 15 种暂不纳入。

本轮确认的主要规范化包括：

| 规范名称 | 可检索别名 | 说明 |

| 新疆准噶尔双峰驼 | 准噶尔双峰驼 | 使用公告规范名称 |

搜索采用规范名称、别名和英文名。部分查询可能自然命中包含相同词段的其他品种，例如“山麻鸭”也会部分匹配“微山麻鸭”；这属于模糊检索，而不是重复记录。

## 4. 数据字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | 字符串 | 稳定英文标识，运行时唯一 |
| name | 字符串 | 馆藏规范中文名，运行时唯一 |
| englishName | 字符串 | 英文展示名，尚未完成权威双语审校 |
| province | 字符串 | 主要关联省份，用于浏览统计 |
| longitude / latitude | 数值 | 科普地图近似落点，不代表精确保种场 |
| category | 枚举 | 猪、牛、羊、鸡、鸭、马、骆驼、兔、鹅、鸽、其他 |
| endangered | 枚举 | 普通、易危、濒危、极危、待核验；属于编辑资料标签，不等同于国家名录 |
| appearance | 字符串 | 体貌编辑资料，历史记录仍需逐条溯源 |
| performance | 字符串 | 生产性能编辑资料，不能替代试验数据 |
| radar | 数值或空值 | 五维编辑归一化指标；无可核验证据时五项全部为 null |
| story | 字符串 | 文化故事与背景资料，历史记录仍需逐条核验 |
| image | 字符串 | 历史外链或项目 SVG 占位路径 |

## 5. 来源与元数据

breedSources.ts 维护来源目录；nationalProtectionList.ts 保存公告中的 271 个畜禽名称；breedMetadata.ts 为每条记录解析：

- officialName：规范名称。
- aliases：审核过的可检索别名。
- protectionStatus：national-list、not-on-national-list 或 unverified。
- sourceIds：可追踪来源标识。
- verifiedAt：本轮核对日期。
- imageRights：verified、unverified 或 project-svg。
- metricBasis：editorial-normalized 或 not-available。

第 940 号公告只证明名称和名录成员身份。不得据此填写“濒危”、五维性能分值、体貌、生产表现、故事或精确坐标。

## 6. 新增记录的保守口径

使用 breed-placeholder.svg 的 22 条净新增记录统一采用：

- endangered 为“待核验”。
- 五维 radar 全部为 null。
- metricBasis 为 not-available。
- 详情页不渲染雷达图，改为“性能指标待补充”。
- 体貌、性能文字、近似点位和文化故事明确标注“编辑资料待逐项核验”。

这样可以保留可浏览的基础档案，同时避免把编辑推断包装成科学测量或权威风险评估。

## 7. 图片索引与版权

完整 701 行图片索引由 pnpm docs:sync 生成至 docs/品种图片索引.csv。来源状态只有两类：

- 历史外链；来源权利待核验。
- 项目 SVG 占位。

没有明确作者与授权的历史图片不应视为可自由复用。项目 SVG 为代码绘制，不代表对应品种的真实外观照片。

## 8. 自动审计规则

auditBreedDataset 会检查：

- ID 和名称是否重复。
- 必填文本字段是否为空。
- 经纬度是否有限且在合法范围内。
- 类别与资料标签是否合法。
- 五维值是否全部为空，或全部为 0–100 的有限数值；禁止空值与数值混用。
- 每条记录是否至少有一个可解析来源。
- 别名是否与其他规范名称或别名冲突。

数据测试还验证 271 个公告畜禽名称的完整覆盖、规范别名、搜索行为和新增记录的证据边界。

## 9. 新增与维护流程

1. 先确认名称与来源，记录核对日期和适用范围。
2. 写失败测试，覆盖身份、重复、搜索、来源和指标口径。
3. 无可靠图片时使用项目 SVG 占位，不虚构作者或授权。
4. 无可核验指标时写 null，不用经验分值补齐图形。
5. 运行 pnpm data:audit 和 pnpm docs:sync。
6. 运行 pnpm check:all，确认桌面与移动端页面、导出和文档一致。
