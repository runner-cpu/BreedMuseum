物种 → 类别 的唯一映射表见 `src/data/speciesCategory.ts`（禁止按名称后缀推断类别）；legacy 历史记录的类别修复见 `src/data/breedCategoryFixes.ts`（27 条，每条可回溯到名录物种），并由 `src/data/__tests__/categorySystem.test.ts` 锁定。

`endangered` 字段取值：`普通` / `易危` / `濒危` / `待核验`（`极危` 为保留值，当前无收录记录，筛选器中不展示）。

## 四、数据字段规范（Breed 接口）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 英文 kebab-case，全局唯一，如 `taihe-silkie` |
| `name` | string | 中文品种名，全局唯一（新增前必须查重） |
| `englishName` | string | 英文译名 |
| `province` | string | 主产省份（标准省名，不含"省/区"后缀） |
| `longitude` / `latitude` | number | 主产地中心坐标（用于地图落点） |
| `category` | string | 类别（见上文 15 类） |
| `endangered` | string | 濒危等级：普通/易危/濒危/待核验 |
| `appearance` | string | 外貌特征（1-2 句） |
| `performance` | string | 生产性能与用途（1-2 句） |
| `radar` | object | 编辑部 0-100 方向性指数：`meat`（产肉）、`milk`（产奶）、`reproduction`（繁殖）、`labor`（役用）、`adaptability`（适应性）；不适用或未核验维度可为 `null`，不代表实测百分位 |
| `story` | string | 品种文化与历史（1-2 句） |
| `image` | string | 图片 URL 或本站路径；优先使用可核验授权来源或项目 SVG 占位图（`/brand/breed-placeholder.svg`），逐条登记于 `docs/品种图片索引.csv` |

**派生元数据（非记录字段）**：记录本身不包含 `source`、`sourceYear`、`sourceStatus`、`radarMethod`、`coordinatePrecision` 等字段。官方名称、别名、国家级保护状态（`protectionStatus`）、核验日期（`verifiedAt`）与引用来源（`sourceIds`）由 `src/data/breedMetadata.ts` 在运行时按品种名称与第 940 号公告名单匹配派生，来源条目定义于 `src/data/breedSources.ts`。

## 七、新增品种标准流程

1. **查重**：用脚本核查品种名是否已存在（见下）。
2. **配图**：优先使用项目原创 SVG 占位图或可核验授权的开放许可图片（如 Wikimedia Commons）；若使用外链图，必须在 `docs/品种图片索引.csv` 登记来源与授权状态，禁止编造 URL。
3. **建文件**：新增 `src/data/extraBreedsN.ts`（N 为下一序号），按 Breed 接口单行条目格式写入。
4. **注册**：在 `src/data/breeds.ts` 顶部 import、导出数组中 spread。
5. **验证**：`npm run lint` 必须通过；统计脚本复测总数与分类。
6. **同步手册**：更新本手册「数据总览」「数据文件结构」「批次变更记录」三处。

## 八、维护脚本

```bash
# 统计总数 / 分类 / 濒危 / 查重（实测口径，禁止手填）
python3 -c "
import re, glob
from collections import Counter
cats, endg, names = Counter(), Counter(), Counter()
for f in sorted(glob.glob('src/data/*.ts')):
    text = open(f).read()
    for c in re.findall(r\"category: '([^']+)'\", text): cats[c] += 1
    for e in re.findall(r\"endangered: '([^']+)'\", text): endg[e] += 1
    for n in re.findall(r\"(?<![a-zA-Z])name: '([^']+)'\", text):
        if re.search(r'[一-鿿]', n): names[n] += 1
print('总条目:', sum(cats.values()), '唯一:', len(names))
print('分类:', dict(cats.most_common()))
print('濒危:', dict(endg.most_common()))
print('重复:', [n for n, c in names.items() if c > 1])
"
```

### 图片替换工作流（Wikimedia 授权图 → 本地托管）
