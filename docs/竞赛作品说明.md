## 一、作品简介

《中国地方畜禽品种数字博物馆》是一个面向公众的畜禽遗传资源科普网站，全量收录《国家畜禽遗传资源品种名录（2024年版）》畜禽在册资源，馆藏 **1088 个**品种条目，覆盖 **31 个省份、11 个类别**（含台湾的地方品种记录）。作品以"宣纸 × 墨绿 × 朱砂"的博物馆视觉语言，把品种地理分布、体貌与生产性能、五维方向性指标、文化故事与国家级保护名录身份整合进六个功能模块，让"农业遗产"以可检索、可对比、可导出的方式走近大众。

## 二、创作背景与立意

中国是全球畜禽遗传资源最丰富的国家之一，《国家级畜禽遗传资源保护名录》（农业农村部公告第 940 号）收录 271 个畜禽品种，但公众能查到的多为零散文本。本作品以"数字博物馆"为载体回答三个问题：**这些品种在哪里**（地图）、**它们长什么样、为何重要**（百科/详情）、**它们的文化与保护现状如何**（故事/看板）。站内全部 271 个公告畜禽名称完成逐一匹配（271/271），并以"数据来源与核验"区块逐条公示来源与核验日期。

## 三、功能模块

| 模块 | 亮点 |
| --- | --- |
| 首页 | 星空 Canvas 背景、聚光灯主视觉地图、3D 类别画廊、精选品种（秦川牛、梅山猪、湖羊、北京鸭等 12 个名品） |
| 品种地图 | SVG 中国地图按省份联动，品种坐标落点 + 脉冲高亮，键盘可操作（Enter/Space） |
| 品种百科 | 名称/别名/英文名优先、特征与故事全文匹配（≥2 字符）的双层搜索，名称命中排在全文命中前；虚拟滚动支撑 1088 条流畅浏览 |
| 数据看板 | 6 组图表（省份 TOP15、濒危构成、类别对比、保护名录 Treemap、收录批次时间轴、密度热力图），PNG/CSV 一键导出，图表全部配可读表格摘要 |
| 品种对比 | 最多 4 个品种并排对比五维指标与关键资料，可导出 |
| AI 助手 | 对话/报告/图片生成/图片识别四种模式；**无后端配置时自动回退到浏览器本地检索**，断网仍可查询与导出 PDF 报告 |

## 四、内容严谨性设计（本作品的差异化重点）

- **来源公示**：每条品种详情内置"数据来源与核验"区块，标注官方名称、保护状态（对第 940 号公告逐名核对）、核验日期与可点击的公告链接。
- **诚实标注**：五维分值明确标注"编辑归一化指标（非实测）"，濒危标签标注"编辑资料、待逐项核验"，未核验记录标"待核验"——不把估计值伪装成权威数据。
- **图片版权透明**：约 679 条历史外链图统一标注"来源权利待核验"，22 条项目原创 SVG 占位图，逐条状态公开于 `/audit/breed-images.csv`，并在《隐私与 AI 使用说明》中列明权利人处理承诺与替换计划。
- **数据工程**：以官方名录为基准：OCR 解析名录 PDF 全部 1431 个条目并与馆藏差集比对，全量收录其畜禽在册资源（地方品种、培育品种/配套系与蜂遗传资源），经运行时归一化并剔除混入的引入品种后得到 1088 条，由数据审计测试守护；名录条目以"待核验"诚实标注并区分于编辑精修词条；两份手册（《品种数据手册》《网站说明书》）与代码保持同步校验。

## 五、技术实现

- **前端**：Vite + React 18 + TypeScript，Tailwind CSS 语义化设计令牌（浅色/深色/跟随系统），Radix UI 无障碍组件，Recharts 可视化，React Router（HashRouter，静态托管零改造）。
- **工程化**：GitHub Actions 双工作流——质量门禁（类型检查、Biome、83 项单元测试、文档一致性校验、构建、打包体积预算、24 项 Playwright 双视口 E2E，含全路由零 console 错误断言）+ 自动部署 GitHub Pages。
- **可达性**：跳转链接、焦点样式、aria-live 结果计数、44px 触控目标、`prefers-reduced-motion` 适配、中英文切换同步 `<html lang>`。
- **性能**：路由级代码分割、数据 chunk 惰性加载、图片懒加载 + 失败占位回退、入口与首载体积受 CI 预算约束。

## 六、原创性与素材说明

站点品牌标识（馆标/字标/favicon/占位插画）均为项目原创 SVG；界面文案为团队撰写；品种数据依据公开权威资料整理并逐条标注状态；深色模式、无障碍与工程链路均为自主搭建。图像素材的授权状态按第"四"节方式公开披露，不存在未声明的素材使用。

## 七、运行方式

```bash
pnpm install
pnpm dev          # 本地开发
pnpm check:all    # 全量质量门禁（类型/代码/测试/文档/构建/预算/E2E）
pnpm build:pages  # 生成 GitHub Pages 发布包（含审计报告与图片索引）
```

无需任何后端配置即可浏览全部馆藏内容；AI 增强功能为可选项。
