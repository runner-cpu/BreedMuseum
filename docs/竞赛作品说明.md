# 中国地方畜禽品种数字博物馆 · 竞赛作品说明

> 参赛类别：自主选题类 · 数字艺术与可视化设计类（数据可视化方向）
> 线上地址：https://runner-cpu.github.io/BreedMuseum/
> 代码仓库：https://github.com/runner-cpu/BreedMuseum

## 一、作品简介

《中国地方畜禽品种数字博物馆》面向公众呈现 1186 条地方畜禽品种记录，覆盖 31 个省级行政区和 15 个类别。主展项「畜种光图」把 46 页官方名录 PDF 转成一张可直接阅读的 2D 数据地图：1062 条可落点记录聚成 161 个产区点位，省块色阶表达分布，点位对应真实坐标，选中后在详情面板查看品种与产区。地图镜头、类别筛选和省份速览把“先看见，再查证”变成一条明确的用户路径。

首页按「看 · 查 · 玩」组织。观众从序厅进入地图探索、品种百科或数据看板，再进入三台数据驱动的互动装置。百科卡片和详情面板承载单个品种信息，所有记录都标注证据边界，待核验产区保留在馆藏中但不伪造地图落点。

## 二、创作背景与立意

地方畜禽品种承载着农耕文明、地域生态与育种经验。公开资料往往分散在 PDF 和名录表格中，公众难以建立整体认知。本作品把来源、核验过程和不确定性同时摊开：地图负责建立空间印象，互动厅负责让观众动手使用真实字段，百科详情负责让每条记录回到清晰的数据边界。作品选择 2D SVG 作为主展项，确保低端设备与移动端也能获得完整信息密度。

## 三、功能模块

| 模块 | 亮点 |
| --- | --- |
| 序厅首页（`/`） | 用四个馆藏数字、地图/百科/看板入口和精选卡片建立参观路线；首页搜索直接进入百科筛选。 |
| 地图探索（`/explore`，`/map`） | 「看」板块展示省块色阶与 161 个产区点位；全部分布、国家级保护、濒危之窗三种镜头与类别下拉筛选；点位和省份打开详情面板。 |
| 品种百科（`/encyclopedia`） | 「查」板块按名称、别名、类别、省份和濒危等级筛选；卡片打开 `?breed=<id>` 详情面板，可加入对比或跳回地图。 |
| 数据看板（`/dashboard`） | 展示类别构成、省份排行、保护与濒危分布、字段覆盖度和坐标落点比例，帮助观众理解数据口径。 |
| 品种对比（`/compare`） | 并列查看最多四条记录的体貌、生产性能、濒危标注和文化故事。 |
| 互动厅（`/arcade`） | 「玩」板块提供找家挑战、识图挑战、知识问答三台装置。题目只使用已核验字段，答错找家题会给出距真实产区的公里反馈。 |

## 四、内容严谨性设计

- **三级核验徽章**：`official` 表示官方名录或 940 号公告可追溯，`editorial` 表示项目整理资料，`pending` 表示仍待专项核验。
- **数据边界说明**：省块颜色和点位位置分别对应已核验记录量与真实坐标；镜头颜色、点位选中状态和装饰性样式不代表额外事实，数据看板与文档明确标注统计口径。
- **出题红线**：互动题仅从 1062 条可落点记录生成，待核验记录不作题目或干扰项；照片认品种模式因已核验授权照片为 0 张而关闭。
- **图片版权透明**：历史外链仅披露为待核验，百科详情优先使用项目原创 SVG 占位图，授权图片登记后才会展示。

## 五、技术实现

- **前端**：Vite、React 18、TypeScript、Tailwind CSS、React Router HashRouter、Recharts 和 Radix UI，全部静态构建并部署到 GitHub Pages。
- **2D 可视化**：SVG 省域路径与纯函数地理聚合模块。记录按同省、平面距离不超过 0.22 的规则确定性合并为产区簇；省份数量通过色阶映射，产区点位对应真实坐标，选中点通过颜色和尺寸变化提示当前详情。
- **可达性与动效**：省份轮廓、镜头 Tab、地图点位和互动选项都可键盘操作；`prefers-reduced-motion` 下直接呈现静态帧；地图不依赖 WebGL。
- **质量门禁**：GitHub Actions 在部署前运行类型检查、Biome、单元测试、数据审计、文档同步、构建、包体预算和 Playwright 桌面/移动双视口测试。

## 六、原创性与素材说明

馆标、字标、favicon、占位插画和 15 类品种剪影均为项目原创；省域轮廓和名录数据来自公开资料并按来源链登记。站内不调用在线生成式 AI，也不把未核验外链图片当作展品。可视化映射和数据边界在地图、百科、数据看板与项目文档中公开说明。
