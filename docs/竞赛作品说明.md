# 中国地方畜禽品种数字博物馆 · 竞赛作品说明

> 参赛类别：自主选题类 · 数字艺术与可视化设计类（数据可视化方向）
> 线上地址：https://runner-cpu.github.io/BreedMuseum/
> 代码仓库：https://github.com/runner-cpu/BreedMuseum

## 一、作品简介

《中国地方畜禽品种数字博物馆》面向公众呈现 1186 条地方畜禽品种记录，覆盖 31 个省级行政区和 15 个类别。主展项「畜种光图」把 46 页官方名录 PDF 转成一张可直接阅读的 2D 数据地图：1062 条可落点记录聚成 161 个产区，省块五档色阶表达分布，产区环的位置对应真实坐标，弧段表达类别构成，金色外环表达国家级保护身份。四个镜头和省份速览把“先看见，再查证”变成一条明确的用户路径。

首页按「看 · 玩 · 查」组织。观众先看地图，再进入三台数据驱动的互动装置，最后在档案区检索单个品种并追到官方来源。所有记录都标注证据边界，待核验产区保留在卷宗里但不伪造落点。

## 二、创作背景与立意

地方畜禽品种承载着农耕文明、地域生态与育种经验。公开资料往往分散在 PDF 和名录表格中，公众难以建立整体认知。本作品把来源、核验过程和不确定性同时摊开：地图负责建立空间印象，互动厅负责让观众动手使用真实字段，卷宗负责让每个判断回到官方文件。作品选择 2D SVG 作为主展项，确保低端设备与移动端也能获得完整信息密度。

## 三、功能模块

| 模块 | 亮点 |
| --- | --- |
| 光图首页（`/`） | 「看」板块展示省块五档色阶、161 个产区环和类别弧段；四个镜头切换结论句；首次进入按省份数量依次点亮；点省份出现速览条与卷宗 chips。 |
| 互动厅（`/arcade`） | 「玩」板块提供找家挑战、识图挑战、知识问答三台装置。题目只使用已核验字段，答错找家题会给出距真实产区的公里反馈。 |
| 品种卷宗（`/breed/:id`） | 「查」板块进入档案编号、批次、三级核验徽章、体貌、性能、五维雷达和官方来源链。未核验历史外链不作为首图，统一使用项目 SVG 占位图。 |
| 馆史与库房（`/about`） | 展示建馆路线、来源链、三态徽章、诚实映射表、质量仪表盘、AI 使用披露与第三方资源。 |

## 四、内容严谨性设计

- **三级核验徽章**：`official` 表示官方名录或 940 号公告可追溯，`editorial` 表示项目整理资料，`pending` 表示仍待专项核验。
- **诚实映射表**：省块颜色、产区位置、环径、弧段、金环和橙环分别对应声明字段；尺寸、亮度和排序不映射数据。
- **出题红线**：互动题仅从 1062 条可落点记录生成，待核验记录不作题目或干扰项；照片认品种模式因已核验授权照片为 0 张而关闭。
- **图片版权透明**：历史外链仅披露为待核验，卷宗首图使用项目原创 SVG 占位图，授权图片登记后才会展示。

## 五、技术实现

- **前端**：Vite、React 18、TypeScript、Tailwind CSS、React Router HashRouter、Recharts 和 Radix UI，全部静态构建并部署到 GitHub Pages。
- **2D 可视化**：SVG 省域路径与纯函数地理聚合模块。记录按同省、平面距离不超过 0.22 的规则确定性合并为产区簇；省份数量通过五档分位数色阶映射，产区环通过类别弧段、金色保护环和濒危环补充语义。
- **可达性与动效**：省份轮廓、镜头 Tab、产区环和互动选项都可键盘操作；首次点亮动画总时长不超过 1.4 秒，`prefers-reduced-motion` 下直接呈现静态帧；地图不依赖 WebGL。
- **质量门禁**：GitHub Actions 在部署前运行类型检查、Biome、单元测试、数据审计、文档同步、构建、包体预算和 Playwright 桌面/移动双视口测试。

## 六、原创性与素材说明

馆标、字标、favicon、占位插画和 15 类品种剪影均为项目原创；省域轮廓和名录数据来自公开资料并按来源链登记。站内不调用在线生成式 AI，也不把未核验外链图片当作展品。所有可视化映射均在馆史页公开说明。

## 七、运行方式

