## 一、作品简介

《中国地方畜禽品种数字博物馆》是一座面向公众的畜禽遗传资源数字博物馆，馆藏 **1186 个**品种条目，覆盖 **31 个省份、15 个类别**（类别口径与名录分组对齐：传统畜禽分畜种、茸鹿类单列、蜂遗传资源单列、其余特种畜禽成组；含台湾的地方品种记录）。

主展品是 **「畜种光图」**：把一份 46 页的官方名录 PDF，变成一座可以拖着转的 3D 中国——**1062 份可落点的官方核验档案，各自在真实产区坐标上亮起一束光**，省的挤出高度按该省馆藏量分级。四个镜头（全部分布 / 类别构成 / 国家级保护 / 濒危之窗）切换看法，点任意一束光直达品种卷宗；每一束光都能顺着来源链点回官方 PDF。

配套两个展项：**互动厅**三台可动手的装置（找家挑战 / 识图挑战 / 知识问答，出题只用已核验字段），**馆史页**把来源链、诚实映射表、质量仪表盘与 AI 使用披露一次说清。

## 二、创作背景与立意

中国是全球畜禽遗传资源最丰富的国家之一，《国家级畜禽遗传资源保护名录》（农业农村部公告第 940 号）收录 271 个畜禽品种，但公众能查到的多为零散文本。既有的数字资源大多停在"可检索的表格"，缺少让人愿意停留的入口。

本作品换了一个思路：**先让人被看见，再让人去查证**。观众打开首页看到的第一件事不是表格，而是一片会发光的中国——"你家的省份亮了几个？"这个钩子把地域认同直接接上馆藏数据。愿意点进去的人，会看到一座把话说清楚、也把话说不到的边界标出来的博物馆：每条记录的官方身份、编辑口径、待核验项，各自有明确的徽章与图例；馆史页里有一张「诚实映射表」，逐行说明每个视觉通道对应哪个已核验字段，并显式列出**不映射**的通道。

## 三、功能模块

| 模块 | 亮点 |

## 四、内容严谨性设计（本作品的差异化重点）

- **三级核验徽章**：由 `src/data/verification.ts` 单点判定——`official`（命中第 940 号公告或 2024 名录来源，🏛）、`editorial`（编辑整理，📄）、`pending`（省份待核验或坐标为哨兵，⏳），全站统一，不在页面各处重复判断。
- **诚实映射表**：馆史页逐行说明「柱体平面位置 = 真实经纬度（同省相邻坐标聚为产区簇）」「柱体高度与粗细 = 该产区品种数」「柱身分段色相 = 类别构成」「柱顶金环 = 第 940 号公告保护身份（271）」「柱底橙环 = 编辑口径濒危（82）」「省块挤出高度 = 该省馆藏量四分位」等，并显式声明**不映射**的通道（尺寸、亮度、排序），避免观众从视觉尺寸反推不存在的数据结论。
- **出题红线**：互动厅只从 1062 条可落点核验记录出题，保护身份题只取 940 号公告名单，省份题从不出现「待核验」；页面公示这条红线，也公示「照片认品种」模式因已核验本地图片为 0 张而**未启用**。
- **图片版权透明**：668 条历史外链图统一标注"来源权利待核验"，518 条项目原创 SVG 占位图，逐条状态公开于 `/audit/breed-images.csv`，并在《隐私与 AI 使用说明》中列明权利人处理承诺；**不拿未经核验的照片当展品**，是本作品刻意付出的代价。
- **数据工程**：以官方名录为基准，按《国家畜禽遗传资源品种名录（2024年版）》（畜资委办〔2025〕18号）官方 PDF 逐页建立机器可读台账（1129 条；引入品种/配套系 171 条与蚕资源整体排除，范围内 958 条）；与 687 条归一化历史记录合并、展开为运行时 1186 条，其中 1062 条带可用坐标、124 条省份待核验（不进入地图与省份统计，但在卷宗页可见并标⏳）。台账 JSON、来源登记与数据审计测试共同守护，文档与代码同步校验。

## 五、技术实现

- **前端**：Vite + React 18 + TypeScript，Tailwind CSS 语义化设计令牌（浅色/深色/跟随系统），Radix UI 无障碍组件，Recharts（卷宗页五维雷达），React Router（HashRouter，静态托管零改造）。
- **3D**：Three.js + `@react-three/fiber` + `drei`（只取 `OrbitControls`/`ContactShadows`/`Edges`）。省域 SVG 经自研管线（`src/lib/geo3d/`）解析为 `ExtrudeGeometry`：34 条路径 → 329 个子路径 → 面积过滤丢弃 282 个零面积噪声环 → 保留 47 环 / 2875 点 → 孔洞按质心 point-in-polygon 判定（福建 1 处真孔洞）→ 无有效环的澳门降级为发光圆点 + 常驻标签，保证"34 个行政区一个不缺"且不伪造几何。
- **渲染纪律**：每个产区只建一根堆叠柱（柱身按类别分段，柱顶金环、柱底橙环各一层环面），不使用每记录一个实例的做法；**零后处理、零 HDR**；`dpr` 上限 2；相机补间用 `useFrame` 里的手写 lerp（≤1.2s），不引入 gsap；系统 `prefers-reduced-motion` 时切静态帧并停用自动旋转。
- **工程化**：GitHub Actions 双工作流——质量门禁（类型检查、Biome、137 项 Vitest 单元/组件测试、11 类数据审计、文档一致性校验、构建、打包体积预算、42 项 Playwright 双视口 E2E，含全路由零 console 错误断言）+ 自动部署 GitHub Pages。
- **可达性**：3D 不是唯一入口——镜头是标准 Tab，省份聚焦是按钮，产区柱拾取有等价的省份列表；键盘可达全部装置；44px 触控目标；中英文切换同步 `<html lang>`。
- **性能**：路由级代码分割（光图场景 504 KB / 134 KB gzip 独立成块）、数据 chunk 惰性加载、图片懒加载 + 占位回退、入口与首载体积受 CI 预算约束。

## 六、原创性与素材说明

站点品牌标识（馆标/字标/favicon/占位插画）、15 类品种剪影 SVG 均为项目原创；界面文案为团队撰写；3D 省域几何由公开的中国省份轮廓路径经自研管线生成，工程实践参考了开源项目 `dora-ljh/china-map-3d`（MIT）的坐标约定与渲染纪律（已在馆史页署名，未复用其数据、动画库或后处理方案）；品种数据依据公开权威资料整理并逐条标注状态。深色模式、无障碍与工程链路均为自主搭建。图像素材的授权状态按第四节方式公开披露，不存在未声明的素材使用。

## 七、运行方式

```bash
pnpm install
pnpm dev          # 本地开发
pnpm check:all    # 全量质量门禁（类型/代码/单测/数据审计/文档/构建/预算/Pages 打包/E2E）
pnpm build:pages  # 生成 GitHub Pages 发布包（含审计报告与图片索引）
```

无需任何后端配置即可浏览全部馆藏内容；本站不调用任何 AI 服务。
