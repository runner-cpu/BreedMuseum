## 1. 现状诊断：为什么"高原定位"下还能看到云南、四川、广东的品种

### 1.1 直接原因：两次定位叠加、但范围没有收敛

| 时间线 | 定位 | 留下的资产 |
| --- | --- | --- |
| 第一阶段（立项） | **全国地方畜禽品种数字博物馆** | 1186 条全量馆藏（2024 国家名录全量核对）、地图/百科/看板三大全量模块、全国 31 省叙事、文档体系 |
| 第二阶段（上一轮改进） | 叠加"高原特色"叙事 | 高原 Hero、青海精选品种、牧场 THI 决策台、品种推荐引擎、66 条高原统计 |

两个阶段**共存但没有分层**：新叙事只改了"门面"（首页 Hero、精选、两个工具），底层数据与百科/地图/看板仍是全国全量。于是出现评委视角的合理质疑：

- 首页说"守护高原畜禽种质资源"，点进百科却有云南 84 条、四川 80 条、广东 66 条、江苏 53 条；
- 推荐引擎的规则表里混着**湖羊、小尾寒羊、滩羊、辽宁绒山羊**等低海拔农区品种，与"高原"主题自相矛盾；
- 文档口径分裂：`docs/竞赛作品说明.md` 仍写"1088 条 / 秦川牛 / 梅山猪"，`README.md` 首行写 1088、统计表却是 1186。

### 1.2 数据层面的实测问题（2026-10-08 快照）

| 编号 | 问题 | 实测证据 | 影响 |
| --- | --- | --- | --- |
| D1 | 高原 66 条中 22 条（33%）分类为"其他" | 青海 28 条中 9 条、西藏 38 条中 13 条为"其他"，其中 18 条从名称即可判定应为牛（6 条，如 娘亚牦牛）或羊（12 条，如 色瓦绵羊） | "11 个类别"统计在高原语境下失真，看板与地图筛选错乱 |
| D2 | 高原 66 条中 24 条（36%）雷达指标全空 | `RADAR_ALL_NULL = 24`，无半空记录 | 对比页/看板出现大片空白，观感差 |
| D3 | 故事文本高度模板化 | 5 个模板句各自出现 114–132 次；33 条记录在同一段故事内自我重复 | 品种详情可信度与阅读体验打折，答辩时易被追问 |
| D4 | 近义/疑似重复未合并 | 高原内已发现：藏猪↔林芝藏猪、藏牛↔西藏牛、青海双峰驼↔柴达木双峰驼 | 同物异名会稀释"28 个青海品种"的含金量 |
| D5 | 124 条省份"待核验"、124 条坐标为哨兵 (0,0) | 现有机制已在统计中排除，但首页数字与百科总数口径需要显式说明 | 数字对不上时无话术兜底 |
| D6 | 保护名录匹配口径未落到高原语境 | 940 号公告匹配：高原 66 条中命中 14 条（青海 7 + 西藏 7），但首页只讲"青海 7 个国家级保护" | 故事有料但未组织成体系 |
| D7 | 濒危标签口径 | 高原实测：濒危 9（青海 3：西宁马、柴达木牛、白唇鹿；西藏 6）、易危 16、普通 17、待核验 24 | 数字可用，但需在页面标注"编辑口径" |

### 1.3 结论：不是"删数据"，而是"分层 + 收敛叙事"

全量数据本身是资产（完整性、可对比性、评审信任度），**问题在于把两类内容放在了同一层叙事里**。框架的解法：

> **一个平台、三层数据、四个抓手。**
>
> - 三层数据：T1 高原主场（66）→ T2 高寒辐射带（待审定）→ T3 全国对照库（其余，降级为"国家名录底图"）；
> - 四个抓手（全部只服务 T1+T2）：**算**（THI 决策台）、**荐**（推荐引擎）、**图**（三层地图）、**证**（来源核验链）。

## 2. 定位重构

### 2.1 一句话定位（新）

> **高原畜禽种质资源数智服务平台**——把国家名录、品种档案与牧区决策工具装进一个纯前端网站：查得准（逐条来源核验）、算得快（THI 热应激即时计算）、荐得明（规则可解释的品种推荐）、讲得动人（三江源叙事 + 数据看板）。

### 2.2 三层数据战略

| 层 | 名称 | 范围（实测/待审定） | 在站点中的角色 | 允许出现的模块 |
| --- | --- | --- | --- | --- |
| T1 | **高原主场库** | 青海 28 + 西藏 38 = **66**（已实测） | 全站叙事与工具的唯一核心 | 首页数字、决策台、推荐引擎、地图默认层、看板默认层、精选、看板导出 |
| T2 | **高寒辐射带** | 候选：甘南、阿坝、甘孜、迪庆、帕米尔、祁连山等产区的牦牛/藏羊/藏猪群（数据中 31 条牦牛全部为候选，需逐条按产区海拔与生态区审定） | 决策工具的"邻近选项"，与 T1 合并参与推荐 | 推荐引擎（标注"辐射带品种"）、地图第二层 |
| T3 | **全国对照库** | 其余 1100+ 条（云南 84、四川 80、广东 66、江苏 53……） | 国家名录底图：证明"数据完整、可追溯"，供对比与研究 | 百科（带"高原优先"排序）、地图全国层、对比页、看板"全国底图"折叠区 |

**为什么保留 T3（答辩标准话术）：**

1. 完整性是数据可信度的一部分：馆藏 = 2024 名录全量核对（含 124 条"待核验"透明标注），不是挑选过的样张；
2. 对比价值：高原品种的独特性（耐寒、耐低氧）只有放到全国坐标系里才讲得清楚；
3. 诚实性：删掉数据制造的"全部是高原品种"印象反而是不诚实的，分层展示才是。

## 5. 数据架构（核心）

### 5.1 建议的运行时模型扩展

现有 `Breed` 接口（单层）：`id / name / englishName / province / longitude / latitude / category / endangered / appearance / performance / radar / story / image`。

建议新增 3 组字段（不破坏既有消费方，全部可选，由审计测试守护）：

```ts
export type PlateauTier = 'core' | 'extended' | 'reference'; // T1 / T2 / T3
export type VerificationLevel = 'official' | 'provincial' | 'editorial'; // 名录级 / 省公告级 / 编辑级

interface Breed {
  // ...既有字段
  tier?: PlateauTier;             // 默认由 province + 产区规则推导
  verification?: {
    identity: VerificationLevel;  // 名称/名录身份
    description: 'verified' | 'editorial' | 'pending'; // 体貌/性能描述
    image: 'licensed' | 'placeholder' | 'external-pending';
  };
  protection?: { national?: boolean; sourceId?: 'moa-940' | 'nahs-catalog-2024' };
}
```

### 5.2 三层判定规则（机器可审计）

1. **T1** = `province ∈ {青海, 西藏}`（66 条，实测锁定）；
2. **T2** = 产区位于青藏高原生态区外延（甘南、阿坝、甘孜、迪庆、帕米尔、祁连山牧区）**且** 有产区描述证据的品种；逐条进入 `tier: 'extended'` 白名单，禁止按省份一刀切（否则甘肃 27 条会误扩）；
3. **T3** = 其余全部；`tier` 缺省视为 `reference`。

**审计断言（加入 `data:audit`）：**
- `tier === 'core'` 的记录数恒等于 `COLLECTION_SUMMARY.plateau`（66）；
- 推荐引擎规则表引用的每个 `id` 必须 `tier ∈ {core, extended}`，否则测试失败；
- 首页四数字必须全部来自 `COLLECTION_SUMMARY`（含 `plateau`、`plateauProtected`、`plateauEndangered` 三个新常量）。

## 6. 功能模块详设

### 6.1 首页

- **Hero**：高原牧场大图（项目原创 SVG，`plateau-hero.svg`）+ 压暗层 + 双行标题 + 出发按钮；
- **四数字**：66 青藏高原品种（副标：青海 28 + 西藏 38）/ 14 国家级保护（青藏）/ 9 濒危（编辑口径）/ 38 西藏（或合并做 28·38 双卡）——最终以 `COLLECTION_SUMMARY` 常量为准，禁止硬编码；
- **三入口**：牧场决策台（THI 色带预览）、品种推荐（评分条预览）、品种地图（点位预览）；
- **青海精选 12**：青海高原牦牛、环湖牦牛、玉树牦牛、大通牦牛、泽库羊、贵德黑裘皮羊、青海黑藏羊、大通马、柴达木双峰驼、互助猪、海东鸡、青海毛驴（欧拉羊为甘肃，仅可在"辐射带"语境出现）；
- **四幕故事**：源（三江源与品种起源）→ 守（保护名录与濒危）→ 用（THI + 推荐）→ 兴（乡村振兴答卷）；
- **来源脚注**：口径说明（覆盖省份不含待核验；青藏高原 = 青海+西藏；濒危为编辑标签）。

### 6.2 牧场环境决策台（算）

- **输入**：畜种（牦牛/藏羊/山羊/马/驼/鸡/猪）、日间温度、湿度、海拔、畜龄；
- **模型**：`THI = T − (0.55 − 0.55×RH)(T − 14.5)`；海拔修正：2000m 起每 1000m −1.2（封顶 −3.6）；畜龄：幼 +1.5 / 老 +0.5；七畜种四级阈值；
- **输出**：大数字 + 绿/黄/橙/红分级色带 + 仪表盘 + **三条优先管理动作**（危险级固定为：开启通风/喷淋 → 缩短并改晨昏放牧 → 夜间补饲能量料）+ 补充措施 + 公式折叠说明；
- **边界文案**：教学演示口径，不替代兽医指导；离线可用；无账号无上传。

### 6.3 品种推荐引擎（荐）

- **输入**：海拔区间（4 档）× 养殖目的（肉/奶/毛绒/役/蛋）× 饲养模式（放牧/舍饲）；
- **规则库瘦身（P0）**：删除 `湖羊、小尾寒羊、滩羊、蒙古羊、哈萨克羊、阿勒泰羊、辽宁绒山羊、太行山羊、中卫山羊、内蒙古绒山羊、河西绒山羊` 等低海拔农区规则；保留 T1 全部 + T2（甘南/川西/滇西北等）牦牛与藏系品种；
- **评分 v2**：海拔匹配 40 分 + 用途匹配 30 分 + 模式匹配 20 分 + 核验完备度 10 分（有来源核验资料加分）；
- **展示**：评分进度条 + 海拔/用途/模式三条决策路径（✓ 命中、△ 近似）+ "查看品种详情"跳转；
- **边界**：推荐为规则推演，不构成引种建议。

### 6.4 品种地图（图）

- **图层开关**：高原主场（默认，66）/ 高寒辐射带（T2）/ 全国对照（T3，降透明度）；
- **交互**：省份下钻、类别/保护筛选、点位弹层（名称/类别/保护徽章/详情链接）；待核验坐标不落点（沿用 `hasVerifiedCoordinates`）；
- **讲法**：默认层用饱和度表达"主场"，全国层用低透明度表达"底图"。

### 6.5 数据看板（证）

- **高原指标卡**：66 / 28 / 38 / 14 / 9 / 24（雷达待补）；
- **图表**：类别构成（修复分类后）、省份分布（青海各州/西藏各市若有数据）、保护名录 Treemap、濒危构成、全国底图折叠区；
- **导出**：CSV（UTF-8 BOM、防公式注入）+ PNG；每图配可读表格摘要。

### 6.6 品种百科（查）

- **搜索**：名称/别名/英文名优先 + 全文（≥2 字符）；**高原置顶**排序；
- **筛选**：类别（修复后）、省份、保护名录、核验状态；
- **徽章**：国家级保护 / 濒危（编辑口径）/ 待专项核验；
- **性能**：虚拟滚动（1186 条流畅）。

### 6.7 品种对比（比）

- 最多 4 个并排；五维雷达（编辑口径标注）+ 关键资料表；空指标显示"待核验"；CSV 导出。

### 6.8 AI 助手（增强，可选）

- 四种模式（对话/报告/图片生成/图片识别）；未配置时本地检索回退；回答注明"仅供参考、需独立核验"；提示词默认注入高原语境。

### 6.9 全局能力

导航（8 路由 + 移动菜单）、全局搜索、深浅色跟随系统、中英切换（`<html lang>` 同步）、离线横幅、404 恢复、跳转主内容、44px 触控、`prefers-reduced-motion`。
