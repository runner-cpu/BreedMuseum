# Breed Museum 第二轮质量升级设计

日期：2026-09-29  
状态：已获用户确认，基于 quality-upgrade 分支实施

## 背景与目标

第一轮已经完成 701 条馆藏数据、来源元数据、原创 SVG 品牌资产、HashRouter 静态站和基础自动化检查。本轮不改变“公开静态科普站”的产品定位，也不恢复登录/收藏；重点把审计中最容易影响真实用户的缺陷收敛为可验证的改动：

1. 让百科筛选和品种对比链接可复制、刷新后可复现。
2. 让检索更快且保留别名/规范名匹配能力。
3. 让无障碍用户能理解筛选状态、动画和地图替代信息。
4. 明确 AI 上传/第三方处理的隐私边界，并提供可读文档。
5. 让 Pages 产物检查、SEO 静态资源和发布流程可重复。
6. 保持 701 条数据口径，同时补充“编辑标签、非权威结论”和图片权利边界。

## 设计决策

### 检索与 URL 状态

新增纯函数查询状态模块，统一解析与序列化 search、province、category、endangered 和 breeds 参数。参数只写入非默认值，值按固定顺序编码，非法省份/等级/品种 ID 被丢弃；百科筛选改变时用 replace 回写 URL，对比页从 URL 恢复并同步 Context。这样不会产生无穷历史记录，也能让分享链接复现结果。

检索索引在模块初始化时一次性生成归一化字符串，搜索过程只读索引；保留 officialName、英文名和 aliases。当前仍是子串匹配，不在没有可靠词典时虚构拼音或繁简映射。

### 性能

首页统计使用小型馆藏摘要常量，完整 breeds 仅在地图、百科、看板、详情和 AI 功能需要时加载；Dashboard 改为单次聚合。图片默认懒加载并带 sizes，预加载器限制并发和数量。构建门禁同时报告入口与静态依赖图，Pages 构建必须包含 audit、brand、.nojekyll。

### 无障碍与动效

所有新增交互文案走 i18n；筛选结果提供 role=status、可删除 chips 和可复制链接反馈。动态画廊在 prefers-reduced-motion 下停止 RAF，并提供静态可操作列表。地图保留可视化，同时提供完整的省份/品种列表替代；不把鼠标 hover 当作唯一信息通道。

### 隐私与内容边界

AI 页面在发送前显示第三方处理提示：文本/图片/语音可能离开浏览器，处理用途为回答或识别，项目不承诺长期保存，用户不得上传敏感或可识别个人信息。客户端错误只显示安全文案，不回显供应商异常。公开 docs/隐私与AI使用说明.md 与页面入口保持一致。

### SEO 与发布

补充 robots.txt、sitemap.xml、site.webmanifest 和 JSON-LD；canonical/OG 使用 Pages 的实际基础路径并保留 HashRouter 兼容性。prepare-pages 校验必需入口、静态资源、审计页和品牌资产；新增 GitHub Actions 只做质量门禁，不改变当前 gh-pages 发布源。

## 不在本轮的事项

- 不把 701 条记录扩展成未经核验的“更多”数据；继续使用现有已审计口径。
- 不虚构逐图作者、许可证或新的国家名录证据；图片权利仍标记为待核验。
- 不把 HashRouter 一次性切换为 BrowserRouter；Pages 深层路径迁移需要单独的兼容窗口。

## 验收标准

- 单元测试覆盖查询参数往返、非法值清理、索引匹配和 reduced-motion 分支。
- pnpm.cmd check:all、pnpm.cmd build:pages、Pages node tests、Playwright 全部通过。
- 发布分支无未提交文件，GitHub 源码与 gh-pages 均为普通快进推送；公开首页、审计页、品牌 SVG 和关键 chunk 返回 HTTP 200。
