## 一、产品简介

「中国地方畜禽品种数字博物馆」是一个面向学生、畜牧从业者与科普爱好者的 Web 科普展示平台。平台以《国家级畜禽遗传资源保护名录》为基准，收录 **687 个**中国地方畜禽品种（牛 160、羊 117、猪 116、鸡 86、马 46、其他 42、鸭 37、鹅 29、兔 27、鸽 15、骆驼 12），覆盖 30 个省份，通过可视化地图、品种百科、数据看板、品种对比、AI 助手等形式，立体呈现每个品种的外貌特征、生产性能、濒危等级、地理分布与文化故事。

## 二、目标用户与典型场景

| 用户 | 场景 |
| --- | --- |
| 学生/教师 | 地理、生物课程中查询地方品种分布与特征，导出图表用于作业与课件 |
| 畜牧从业者 | 对比不同品种的生产性能（产肉/产奶/繁殖/役用/适应性），辅助引种决策 |
| 科普爱好者 | 浏览品种故事，收藏感兴趣的品种，用 AI 助手提问与生成内容 |
| 研究人员 | 通过数据看板掌握品种资源家底，导出 CSV 数据做二次分析 |

## 四、页面与功能详解

### 4.1 首页（`/`）

- **GalaxyBackground 星空背景**：Canvas2D 绘制，星点沿椭圆轨道缓慢旋转，密度为常规 3 倍，带闪烁效果与鼠标斥力交互。
- **SpotlightHero 主视觉**：聚光灯效果 + 中国地图（浅色基础图、70% 透明度、完整显示），滚动入场动画。
- **CircularGallery 类别画廊**：3D 旋转圆环展示 11 个畜禽类别卡片，支持拖拽/自动旋转。
- **MagicBento 功能区**：6 张功能入口卡片（品种地图、品种百科、数据看板、品种对比、AI 助手、我的收藏），带辉光、粒子与波纹交互效果。
- **ScrollFloat / ChromaGrid**：滚动文字浮动与彩色网格等视觉增强组件。

### 4.2 品种地图（`/map`）

- SVG 中国地图，按省份着色与品种计数标注。
- 点击省份联动品种列表；品种以坐标落点呈现（`pulseId` 脉冲高亮选中品种）。
- 点击落点/列表项打开 **BreedDetail 详情面板**：品种实拍图、外貌特征、生产性能、五维雷达图（产肉/产奶/繁殖/役用/适应性）、濒危等级、文化故事、分享链接复制、收藏/取消收藏（未登录点击收藏会提示先登录）。

### 4.3 品种百科（`/encyclopedia`）

- 类别筛选（11 类）+ 关键词搜索（名称/特征/故事模糊匹配）。
- 卡片式列表展示品种缩略图、产地、濒危等级徽标，点击进入详情。

### 4.4 数据看板（`/dashboard`）

- 4 张统计卡：品种总数（592）、覆盖省份（30）、濒危品种、普通品种。
- 5 组图表：各省品种数量 TOP15 柱状图（降序）、各类别占比饼图（**点击扇区可跳转百科对应类别**）、类别数量横向对比条、国家级保护品种分布图（面积=品种数，颜色=类别）、各省品种密度热力图。
- 导出能力：看板导出 PNG 图片、数据导出 CSV 文件。

### 4.5 品种对比（`/compare`）

- 从百科/详情页加入对比（`compareIds`），多品种并排对比五维雷达与关键信息。
- 支持导出对比结果图片。

### 4.6 AI 助手（`/ai`）

四种模式，通过顶部工具栏（快捷提问下方、输入框上方）切换：

| 模式 | 说明 | 后端 |
| --- | --- | --- |
| 对话 | 品种知识问答，SSE 流式输出 Markdown | `wenxin-text-generation` |
| 报告 | 围绕指定品种生成结构化研究报告 | `wenxin-text-generation` |
| 图片生成 | 文生图，异步任务轮询 | `submit-image-generation` + `query-task` |
| 品种识别 | 上传照片识别畜禽品种 | `image-understanding-request`（提交）+ `image-understanding-result`（3 秒轮询，3 分钟超时） |

- 快捷提问：6 个预设问题，3 列网格展示。
- 布局：对话区占满视口高度（减去顶栏），消息气泡最大宽度 75%，全宽容器与侧栏对齐。

### 4.7 我的收藏（`/favorites`）

- 展示当前登录用户收藏的品种卡片。
- **批量管理**模式：进入后可多选/全选/取消全选，批量取消收藏，带操作结果 Toast 反馈。

### 4.8 个人信息（`/profile`）

- 展示用户名、手机号、邮箱、账户类型（管理员/普通用户）、注册时间。
- 入口：侧边栏用户菜单；支持从此页退出登录。

### 4.9 登录/注册（`/login`）

- 三种方式：邮箱+密码、用户名+密码、手机号 OTP 验证码。
- 注册字段：用户名（2-12 字符，全局唯一，写入 profiles 并同步 user metadata）、密码、协议勾选。
- 异常处理：对用户名冲突、验证码错误等给出中文提示。

### 4.10 404 页面

- 未匹配路由统一跳转，提示"页面未找到"，可一键返回首页。

## 五、导航与布局

- **桌面端（≥768px）**：左侧固定导航栏（首页/品种地图/数据看板/品种百科/AI助手/我的收藏/品种对比），底部为语言切换、主题切换与用户菜单（登录/个人信息/退出登录）。
- **移动端（<768px）**：汉堡菜单 + Sheet 抽屉导航，点击导航项后自动关闭。
- **RouteGuard**：控制路由的登录访问策略（当前各页面 `public: true`，收藏/个人页内部做登录态判断）。

## 七、数据与后端

### 7.1 品种数据

- 共 **592 个品种**，存于 `src/data/`（`breeds.ts` 基础库 124 条 + 12 个批次文件）。
- 每条含 12 个字段：id、name、englishName、province、经纬度、category、endangered、appearance、performance、radar（五维）、story、image。
- 数据规范、批次记录与新增流程见 `docs/品种数据手册.md`；由「品种数据与手册同步」技能保证数据与手册一致。

### 7.2 数据库

| 迁移 | 内容 |
| --- | --- |
| `00001_create_auth_and_favorites.sql` | `profiles` 表（用户资料）、`favorites` 表（收藏）、新用户触发器、RLS 策略 |
| `00002_create_generated_media_bucket.sql` | `generated-media` 存储桶（AI 生成媒体） |
| `00003_update_handle_new_user_username_and_unique.sql` | 用户名唯一约束与注册同步逻辑更新 |

### 7.3 Edge Functions

| 函数 | 用途 |
| --- | --- |
| `wenxin-text-generation` | 文心大模型流式文本生成（AI 对话/报告） |
| `submit-image-generation` / `query-task` | AI 文生图任务提交与结果轮询 |
| `image-understanding-request` / `image-understanding-result` | 品种图像识别任务提交与结果轮询 |

## 八、国际化与主题

- **双语**：中文/英文一键切换，260+ 条文案键覆盖导航、各页面、AI 助手、表单与提示语；站内无硬编码中文，全部经 `t()` 读取。
- **主题**：浅色/深色/跟随系统三种模式；深色模式以降低阴影、提升表面亮度的方式呈现层次。

## 九、响应式与无障碍

- 桌面优先设计，768px 断点适配移动端；表格横向滚动、卡片等高铁律、触控目标 ≥48px。
- 色彩对比度遵循 WCAG AA；信息不以颜色单独传达（配图标与文字）。

## 十、使用指南（快速上手）

1. 打开首页，滚动浏览类别画廊与功能入口。
2. 进入「品种地图」，点击省份查看当地品种，点击落点查看详情并收藏。
3. 进入「品种百科」按类别/关键词检索品种。
4. 在详情或百科中将品种「加入对比」，到「品种对比」查看雷达对比并导出。
5. 「数据看板」查看全局统计，可导出 PNG/CSV。
6. 「AI 助手」提问品种知识、生成报告、生成图片或上传照片识别品种。
7. 注册/登录后，收藏与个人数据云端保存，可在「我的收藏」批量管理。

## 十一、维护指南
