## 四、页面与功能详解

### 4.1 序厅首页（`/`）

首页是面向公众的序厅，按五段展开：核心数据看板（馆藏 1186 / 可浏览 667 / 覆盖 30 个省级行政区 / 14 个可浏览类别）、品种类别速览（14 类可点击直达百科筛选）、五种进入方式（地图为主入口，百科 / 看板 / 互动厅 / 对比为次级入口）、精选品种（8 条带真实馆藏照片的记录）与关于本项目（数据来源、技术口径、纠错入口）。首屏只保留搜索，不承载完整地图筛选；全局搜索与序厅搜索都统一进入百科的检索状态（`/encyclopedia?search=…`），因为探索页不承载可翻阅的结果列表。首屏数字来自轻量常量 `homeHighlights.ts`，由测试与运行时馆藏逐项比对。

### 4.2 地图探索（`/explore`，`/map` 为兼容别名）

主展项是一张 2D 数据地图：**667 条带图可浏览记录**聚成 **202 个产区点位**，覆盖 **30 个省级行政区**，每个点位对应真实坐标，省块色阶按已核验记录量变化。`/map` 与 `/explore` 使用同一页面。

- **口径说明**：全馆藏 1,186 条中有 1,062 条具备已核验坐标，但地图只绘制同时具备真实图片的记录；因此标题与图注使用 667 / 202 / 30，而不是全量口径的 1,062 / 217。两个口径都由 `COLLECTION_SUMMARY.visibleMappable` / `visibleClusters` 与运行时测试锁定。
- **产区聚类**：667 条带图落点记录按「同省、平面距离 ≤ 0.14」做确定性合并，得到 202 个产区簇；簇中心是记录数加权重心，`clusterSites.test.ts` 锁定覆盖率、偏移上限与顺序无关性。
- **地图编码**：省块颜色 = 该省已核验落点记录数的分位色阶；产区点位 = 真实经纬度聚类中心；点位颜色复用全站 15 类类别色板；点位尺寸只用于选中态提示，不映射额外字段。
- **两条正交筛选轴**：类别栏回答「看哪一类畜种」，镜头条回答「看哪一类证据」（全部落点 / 国家级保护 / 濒危之窗）。两者可叠加，例如「牛 + 国家级保护」当前为 42 条记录 / 39 个产区；状态写回地址栏（`?category=牛&lens=protect`），刷新与分享可复现。
- **详情面板**：点省份或产区点位会打开当前品种详情面板，可加入对比或跳转到百科详情；待核验记录保留在百科中，不伪造地图落点。

### 4.3 品种百科（`/encyclopedia`）

百科按名称、别名、描述、类别、省份和濒危等级筛选 **667 条带图记录**；类别、省份、等级下拉只列出当前有结果的选项，旧链接中的空筛选值会回落到「全部」。点击卡片打开可关闭的详情面板，展示图片状态、类别、省份、体貌、生产性能、文化故事和对比入口；地图详情面板通过 `breed` 查询参数直达同一条百科记录。

### 4.4 馆藏数据看板（`/dashboard`）

数据看板集中展示类别构成、省份数量排行、保护与濒危分布、字段覆盖度和坐标落点比例。图表均从运行时馆藏与 `COLLECTION_SUMMARY` 派生，并提供返回地图、百科和互动厅的入口；待核验省份不参与地图与省份统计。

### 4.5 品种对比（`/compare`）

百科和地图详情面板最多可加入 4 条记录，`/compare` 以表格并列体貌、生产性能、濒危标注和文化故事。没有选择记录时页面提供返回百科的恢复入口。

### 4.6 互动厅（`/arcade`）

**总览页 + 三个子页**：`/arcade` 只做入口，列出三台展教装置的卡片（玩法、局数、数据边界、进场按钮），游客挑一台再进对应子页，避免三台装置挤在一屏里同时答题。

| 子页 | 装置 | 玩法 | 数据边界 |
| --- | --- | --- | --- |
| `/arcade/find-home` | 找家挑战 | 3 轮：给出品种卡与照片，在真实中国地图上点出产区；只有已核验产区的省份可点击，答错显示「方向不对：距真实产区约 N 公里」（haversine） | 只从具备已核验坐标的记录出题 |
| `/arcade/identify` | 识图挑战 | 6 轮：看一张馆藏真实照片选出所属类别，答完给出 3 个同类品种 | 只问类别（可靠字段），不问品种级身份；照片全部来自馆藏记录 |
| `/arcade/quiz` | 知识问答 | 5 题，四种题型循环（省份 / 类别 / 保护身份 / 濒危口径） | 出题只读已核验字段，末题附档案链接 |

- 三个子页顶部都有同一个切换条（`aria-current` 标当前装置），换装置不用退回总览；未知装置 id 自动回落到 `/arcade`。
- 总览页与子页脚注都写着「出题红线」：题目与选项只取已核验字段，待核验记录不出题、也不作干扰项；识图挑战只问类别，因为照片的品种级身份仍待逐条核验。
- 全部装置可用键盘完成（选项为真实 `button`，省份为可聚焦按钮组）；中英文题干、选项与解析均已翻译。

### 4.7 互动装置子页（`/arcade/:game`）与 404

- `/arcade/find-home`、`/arcade/identify`、`/arcade/quiz` 各自只渲染一台装置，未知装置名回到 `/arcade`。
- 未匹配路由显示「页面未找到」，可一键返回首页。
- `/pasture`、`/recommend`、`/ai`、`/home` 四条旧路由保留 `<Navigate replace>` 重定向到 `/`；`/map` 是地图探索兼容别名，不是重定向。
- `/about` 与 `/breed/:id` 已从公开路由中移除，访问时按真实未知路径显示 404；详情使用百科面板和查询参数承载。

## 七、数据与后端

### 7.1 品种数据

- 共 **1186 条站内记录**，存于 `src/data/`（基础库与 15 个扩充批次文件合并、2024 名录增量展开后运行时归一化）；其中 **667 条带图、面向访客浏览**，**1062 条**带可落点坐标，**124 条**省份待核验（不进入地图与省份统计）。地图、百科、看板与页脚统一使用 667 条可浏览口径；`COLLECTION_SUMMARY` 同时保留 1186 / 1062 / 124 的全量字段，供覆盖度图表与文档引用。
- 每条含展示字段：id、name、englishName、province、经纬度、category、endangered、appearance、performance、radar（方向性五维，可为空）、story、image。官方名称、别名、保护状态、核验日期等证据元数据由 `breedMetadata.ts` 按名称匹配第 940 号公告派生，不属于记录字段。
- 三级核验由 `src/data/verification.ts` 单点判定：`official`（命中第 940 号公告或 2024 名录来源）/ `pending`（省份待核验或坐标为哨兵）/ `editorial`（其余）。百科详情面板与地图详情统一使用同一份数据口径。
- 数据规范、批次记录与新增流程见 `docs/品种数据手册.md`；由「品种数据与手册同步」技能保证数据与手册一致。

## 九、响应式与无障碍

- 验收视口包括桌面 1440×900 和移动 390×844。
- 导航、抽屉、镜头 Tab、互动厅选项与省份按钮均可键盘操作，触控目标 ≥44px。
- 色彩对比度遵循 WCAG AA；信息不以颜色单独传达——保护身份用金色 + 文字标签、核验级别用徽章图标 + 文字。
- 地图采用 SVG/CSS 静态帧：低端机与系统「减少动态效果」直接呈现同一套静态数据，互动厅与详情面板共用轻量组件。
- 离线提示使用非阻断状态消息；错误边界提供重新加载和返回光图。
- 页面级元信息按路由设置，标题层级和 404 语义保持独立。

## 十、使用指南（快速上手）

1. 打开 `/`，点「进入地图」进入 2D 光图，使用 3 个镜头和类别下拉切换看法。
2. 点「国家级保护」镜头看 271 条记录的点位，或点「濒危之窗」看 82 条编辑标注（页面注明非权威结论）。
3. 点任意一个地图点位、或在 `/encyclopedia` 输入品种名，打开 **品种详情面板**——看体貌、性能、文化故事和对比入口；待核验记录保留在百科中并明确标注。
4. 去 `/arcade` 选一台装置进子页：找家挑战（答错会给「距真实产区约 N 公里」）、识图挑战、知识问答；子页顶部可随时换装置。
5. 去 `/dashboard` 查看类别、产区、保护状态和字段覆盖度，再通过页脚的隐私与审计入口了解数据边界和 AI 使用说明。

## 十二、视觉与版本沿革

界面采用宣纸米色、墨绿和克制的朱砂强调色，深色模式改用品牌墨绿体系；光图在两套主题下都给出对应的舞台底色（浅色宣纸 / 深色墨绿夜色），保证省块、地图点位与文字对比。项目不再依赖远程字体，避免字体服务不可用或隐私请求带来的首屏风险。

- v1–v2：静态品种库 + 百科/地图/看板/对比。
- v3：五屏滚动叙事首页与热应激决策台（已下线，相关文件保留在 `src/components/effects/`）。
- v4（当前）：**「地图探索」**——2D 地图探索 + 品种百科详情面板 + 数据看板 + 品种对比 + 互动厅，导航为 6 项；4 条历史路径重定向到首页。

## 十三、配置、构建与部署

- 推荐 Node.js 20+ 与 pnpm。
- `pnpm dev` 启动本地开发；`pnpm build` 生成生产文件。
- `pnpm check` 运行类型、代码、测试、文档同步、构建和体积预算。
- `pnpm check:all` 额外构建无配置版本并运行桌面、移动端 E2E。
- `.env.example` 只列变量名和说明，真实密钥不得进入源码或文档。
- HashRouter 适合静态托管；缺点是 URL 带 #，搜索引擎抓取能力有限。
- GitHub Pages 同时发布 `/audit/` 审计报告与品种图片索引（breed-images.csv）、`/privacy.html` 隐私说明（含「图片来源与版权状态」章节）、`robots.txt`、`sitemap.xml` 和原创品牌 SVG；部署前应运行 `pnpm build:pages` 并检查这些静态地址返回 200。
- 数据版本 2026-09-27 表示馆藏快照与来源核对版本；本说明书日期 2026-10-10 表示文档和工程复核日期。

## 十四、已知限制
