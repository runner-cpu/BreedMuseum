# 中国地方畜禽品种数字博物馆网站说明书

版本：质量升级版
更新日期：2026-09-29

## 1. 项目定位

本网站是无需登录即可访问的中国地方畜禽品种科普平台。主要受众为公众、动物科学学生、教师、畜牧从业者和内容研究者。站点强调可探索性与证据透明度，不提供育种、投资、兽医诊断或权威濒危评估结论。

## 2. 页面与导航

| 路径 | 页面 | 主要能力 |
| --- | --- | --- |
| / | 首页 | 品牌介绍、全站搜索、统计与功能入口 |
| /map | 品种地图 | 省份与类别筛选、品种搜索、近似点位、详情面板 |

桌面端使用顶部主导航；移动端提供完整菜单、全站搜索和类别筛选抽屉。所有主要触控目标不小于 44px，并提供“跳到主内容”链接。

## 3. 核心功能

### 3.1 首页

首页使用项目 SVG 标志和字标，展示实际运行时统计，不再使用“1000+”或“全部独立真实配图”等无法验证的宣传。搜索结果可直接进入地图详情。

### 3.2 品种地图

- 支持名称、英文名和别名搜索。
- 搜索词与 breed_id 可写入 URL，便于分享和恢复页面状态。
- 桌面端显示侧栏详情；移动端使用可关闭的底部详情面板。
- 经纬度用于科普地图的近似落点，不等同于精确保种场或核心产区坐标。

### 3.3 品种详情

详情展示名称、英文名、省份、类别、资料标签、体貌、生产性能、文化故事、对比与分享入口，并新增“数据来源与核验”区：

- 规范名称或馆藏名称。
- 国家级保护名录状态，与编辑资料标签分开显示。
- 来源链接与核验日期。
- 图片是历史外链还是项目 SVG 占位。
- 指标是编辑归一化值还是尚无可核验数据。

仅有名称证据的新记录不绘制雷达图，而显示“性能指标待补充”；其体貌、性能文字、近似点位与故事均标注为待逐项核验的编辑资料。

### 3.4 品种百科

百科搜索覆盖正式名称、英文名和审核过的别名。页面取消旧版 50 条硬截断和人为等待，筛选后展示全部匹配记录。结果卡片的图片加载失败时保持版式并切换到品牌 SVG 占位。

### 3.5 数据看板

图表提供可展开的数据表，确保不依赖颜色或鼠标也能读取数值。国家级保护名录成员与编辑资料标签分开统计，密度格可以键盘或触控打开对应数据。

### 3.6 品种对比

无选择时展示清晰空状态和“浏览百科”入口。已选择品种可逐项移除；五维数据表中缺失值显示“待补充”。导出 CSV 包含 UTF-8 BOM，并对以等号、加号、减号或 @ 开头的单元格进行公式注入防护。

### 3.7 AI 助手

AI 为可选能力。没有 Supabase 或相关服务配置时，页面显示“AI 服务尚未配置”，公共地图、百科、看板与对比仍正常工作。流式请求等待完整响应，支持 120 秒超时和用户取消；HTTP 错误不会把服务端正文直接暴露给用户。回答仅供辅助理解，应结合页面来源继续核实。

## 4. 品牌与图标

public/brand 包含以下手写 SVG：

- museum-mark.svg：项目标志。
- museum-wordmark.svg：项目字标。
- favicon.svg：浏览器图标。
- breed-placeholder.svg：品种图片缺失或权利不明时的占位图。

界面采用宣纸米色、墨绿和克制的朱砂强调色，深色模式改用品牌墨绿体系。项目不再依赖远程字体，避免字体服务不可用或隐私请求带来的首屏风险。

## 5. 移动端与无障碍

- 验收视口包括桌面 1440×900 和移动 390×844。
- 导航、抽屉、按钮和可点击密度格可使用键盘操作。
- 图表配有表格摘要，图片有替代文本，装饰图标不进入读屏顺序。
- 离线提示使用非阻断状态消息；错误边界提供重新加载和返回首页。
- 页面级元信息按路由设置，标题层级和 404 语义保持独立。

## 6. 数据来源与版权

第 940 号公告用于核对 271 个畜禽名称和国家级保护名录身份。公告不支持将这些名称直接解释为“濒危”，也不支持推导五维分值。历史叙述、点位和图片仍需逐条核验；图片索引中统一使用“历史外链；来源权利待核验”或“项目 SVG 占位”。在取得作者与明确授权前，不应宣传图片可自由复用。

## 7. 配置、构建与部署

- 推荐 Node.js 20+ 与 pnpm。
- pnpm dev 启动本地开发；pnpm build 生成生产文件。
- pnpm check 运行类型、代码、测试、文档同步、构建和体积预算。
- pnpm check:all 额外构建无配置版本并运行桌面、移动端 E2E。
- .env.example 只列变量名和说明，真实密钥不得进入源码或文档。
- HashRouter 适合静态托管；缺点是 URL 带 #，搜索引擎抓取能力有限。
- GitHub Pages 同时发布 /audit/ 审计报告、/privacy.html 隐私说明、robots.txt、sitemap.xml 和四个原创 SVG；部署前应运行 pnpm build:pages 并检查这些静态地址返回 200。
- 数据版本 2026-09-27 表示馆藏快照与来源核对版本；本说明书/审计日期 2026-09-29 表示文档和工程复核日期。

## 8. 已知限制

- 蜂和蚕尚未进入现有五维数据模型。
- 大量历史图片、故事、点位与五维值缺乏逐条可审计出处。
- 单页应用与 HashRouter 的 SEO 能力有限，关键内容仍依赖客户端渲染。
- breeds 数据块较大，后续可按类别或地区拆分加载。
- 英文界面仍以关键导航词条为主，内容数据并未完成专业双语审校。
- 最新 Vitest 已通过 28 个测试文件、79 项测试；Playwright 双视口本轮仍有失败用例，不能把当前版本描述为 E2E 全链路通过。
