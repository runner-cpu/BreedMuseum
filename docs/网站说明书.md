## 一、产品简介

「中国地方畜禽品种数字博物馆」是一个面向学生、畜牧从业者与科普爱好者的 Web 科普展示平台。平台以《国家畜禽遗传资源品种名录（2024年版）》与公开品种志资料为基准，当前运行时收录 **687 条站内记录**（牛 160、羊 117、猪 116、鸡 86、马 46、其他 42、鸭 37、鹅 29、兔 27、鸽 15、骆驼 12），覆盖 30 个省份，通过可视化地图、品种百科、数据看板、品种对比、本地检索助手等形式，呈现每个品种的外貌特征、生产性能方向性指标、保护标记、地理分布与文化故事。站内记录不等同于官方名录全集。

## 二、目标用户与典型场景

| 用户 | 场景 |
| --- | --- |
| 学生/教师 | 地理、生物课程中查询地方品种分布与特征，导出图表用于作业与课件 |
| 畜牧从业者 | 对比不同品种的生产性能（产肉/产奶/繁殖/役用/适应性），辅助引种决策 |
| 科普爱好者 | 浏览品种故事，按类别/省份检索，用本地助手提问与生成报告 |
| 研究人员 | 通过数据看板掌握品种资源家底，导出 CSV 数据做二次分析 |

## 四、页面与功能详解

### 4.1 首页（`/`）

- **GalaxyBackground 星空背景**：Canvas2D 绘制，星点沿椭圆轨道缓慢旋转，密度为常规 3 倍，带闪烁效果与鼠标斥力交互。
- **SpotlightHero 主视觉**：聚光灯效果 + 中国地图（浅色基础图、70% 透明度、完整显示），滚动入场动画。
- **CircularGallery 类别画廊**：3D 旋转圆环展示 11 个畜禽类别卡片，支持拖拽/自动旋转。
- **MagicBento 功能区**：5 张功能入口卡片（品种地图、品种百科、数据看板、品种对比、AI 助手），带辉光、粒子与波纹交互效果。
- **ScrollFloat / ChromaGrid**：滚动文字浮动与彩色网格等视觉增强组件。

### 4.2 品种地图（`/map`）

- SVG 中国地图，按省份着色与品种计数标注。
- 点击省份联动品种列表；品种以坐标落点呈现（`pulseId` 脉冲高亮选中品种）。
- 点击落点/列表项打开 **BreedDetail 详情面板**：品种实拍图、外貌特征、生产性能、五维雷达图（产肉/产奶/繁殖/役用/适应性）、濒危等级、文化故事、来源说明与分享链接复制。

### 4.3 品种百科（`/encyclopedia`）

- 类别筛选（11 类）+ 关键词搜索（名称/特征/故事模糊匹配）。
- 卡片式列表展示品种缩略图、产地、濒危等级徽标，点击进入详情。

### 4.4 数据看板（`/dashboard`）

- 4 张统计卡：运行时记录总数（687）、覆盖省份、濒危/极危标记记录、普通记录。
- 6 组图表：各省品种数量 TOP15 柱状图（降序）、濒危等级构成、类别数量横向对比条、类别记录 Treemap、批次收录时间轴、各省品种密度热力图。
- 导出能力：看板导出 PNG 图片、数据导出 CSV 文件。

### 4.5 品种对比（`/compare`）

- 从百科/详情页加入对比（`compareIds`），多品种并排对比五维雷达与关键信息。
- 支持导出对比结果图片。

### 4.6 AI 助手（`/ai`）

两种模式，通过顶部工具栏切换：

| 模式 | 说明 | 后端 |
| --- | --- | --- |
| 对话 | 基于本地品种库的规则路由、类别/省份/保护标记筛选 | 浏览器本地执行 |
| 报告 | 基于匹配记录生成 Markdown，并支持 PDF 导出 | 浏览器本地执行 |

- 快捷提问：3 个预设问题，移动端自动换行。
- 布局：对话区占满视口高度（减去顶栏），消息气泡最大宽度 75%，全宽容器与侧栏对齐。

### 4.7 404 页面

- 未匹配路由统一跳转，提示"页面未找到"，可一键返回首页。

## 五、导航与布局

- **桌面端（≥768px）**：左侧固定导航栏（首页/品种地图/数据看板/品种百科/AI助手/品种对比），底部为语言切换与主题切换。
- **移动端（<768px）**：汉堡菜单 + Sheet 抽屉导航，点击导航项后自动关闭。
- 所有展示页面均为公开访问，无登录门槛。

## 七、数据与后端

### 7.1 品种数据

- 共 **687 条站内记录**，存于 `src/data/`（基础库 124 条 + 14 个批次文件）。
- 每条含展示字段与证据元数据：id、name、englishName、province、经纬度、category、endangered、appearance、performance、radar（方向性五维）、story、image、source、sourceStatus、radarMethod、coordinatePrecision。
- 数据规范、批次记录与新增流程见 `docs/品种数据手册.md`；由「品种数据与手册同步」技能保证数据与手册一致。

### 7.2 Edge Functions

| 函数 | 用途 |
| --- | --- |
| Edge Functions | 旧版托管能力保留在仓库，当前前端不调用，避免公开 anon key 驱动外部消费 |
| `kling-3-turbo-text-create` / `kling-3-turbo-query` | 可灵视频生成（已部署，当前 AI 助手界面未开放入口） |

## 八、国际化与主题

- **双语**：中文/英文一键切换，260+ 条文案键覆盖导航、各页面、AI 助手、表单与提示语；站内无硬编码中文，全部经 `t()` 读取。
- **主题**：浅色/深色/跟随系统三种模式；深色模式以降低阴影、提升表面亮度的方式呈现层次。

## 九、响应式与无障碍

- 桌面优先设计，768px 断点适配移动端；表格横向滚动、卡片等高铁律、触控目标 ≥48px。
- 色彩对比度遵循 WCAG AA；信息不以颜色单独传达（配图标与文字）。

## 十、使用指南（快速上手）

1. 打开首页，滚动浏览类别画廊与功能入口。
2. 进入「品种地图」，点击省份查看当地品种，点击落点查看详情并复制分享链接。
3. 进入「品种百科」按类别/关键词检索品种。
4. 在详情或百科中将品种「加入对比」，到「品种对比」查看雷达对比并导出。
5. 「数据看板」查看全局统计，可导出 PNG/CSV。
6. 「AI 助手」提问品种知识或生成报告。
7. 在 AI 助手中使用本地检索和报告导出，断网时仍可查询静态数据。

## 十一、维护指南

| 任务 | 方法 |
| --- | --- |
| 新增品种 | 遵循 `docs/品种数据手册.md` 第七节流程（查重→配图→新批次文件→注册→lint→同步手册），由 breed-data-manual-sync 技能强制约束 |
| 修改文案 | 在 `src/contexts/AppSettings.tsx` 的中英文案表中增改键值，页面用 `t('键')` 引用 |
| 修改导航 | 编辑 `src/routes.tsx` 路由表 + `src/components/layouts/Layout.tsx` 导航项 |
| 验证 | `npm run lint`（构建+静态检查）必须通过 |
