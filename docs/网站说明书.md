## 四、页面与功能详解

### 4.1 光图首页（`/`）

主展品是一座可旋转的 3D 中国：**1062 条可落点记录**先聚成 **161 个产区**，每个产区立一根按类别分段的堆叠柱，省块挤出高度按该省馆藏量四级变化。

页面构图是「**满高展台 + 右侧展签栏**」：左侧展台占满可视高度（≥lg），HUD 浮在展台上；右侧展签栏承载检索、省份聚焦与数据摘要。窄屏（<lg）时展签栏落到展台下方、整页可滚动，展台仍保留 62vh 主要视高。

- **舞台配色**：展台底色、省块、产区柱、展签栏全部读同一套 `stage*` 语义令牌（`src/lib/stagePalette.ts`）。浅色＝宣纸（`#f1ece0`）+ 更深的宣纸棕版图（`#c2ad78`）+ 描边 `#3f3627`；深色＝墨绿夜色（`#0a100e`）+ 省块 `#2c4636` + 描边 `#86b79a`。省块之下铺一层展台台面（`floor`），使版图「落在台面上」而不是浮在虚空里；三者的明度关系由 `stagePalette.test.ts` 断言锁定。
- **取景**：不是「半径 × 系数」估算，而是把版图主体包围盒的 8 个角投影进视锥解析求解（`src/lib/geo3d/cameraFit.ts`），候选俯角各解一次取屏幕占比最大者，再把目标点平移到 HUD 之间的可见带中心。横屏俯角上限 55°（保住柱体的「柱」形），竖屏放宽到 73°（把横带铺满窄屏）。
- **唯一坐标原点**：省块几何、省域质心、取景包围盒与产区柱投影全部经 `buildProvinceGeometry` 的 `toPlane()` 换算到「视图中心为原点」的同一平面；`geometry.test.ts` 用投影四角与省块包围盒对齐断言防止图层再次错开半张地图。
- **产区聚类**：1,062 条落点记录只落在 509 个坐标上（102 个坐标挤了 655 条，最大的一个 45 条）。`clusterSites.ts` 按「同省、世界距离 ≤ 0.22」做确定性贪心合并，得到 161 个产区簇；簇中心是记录数加权重心，簇内最大偏移有硬上限，`clusterSites.test.ts` 锁定覆盖率、偏移上限与顺序无关性。
- **柱体编码**：柱高与底面半径对应该产区的品种数（对数压缩），柱身按类别分段（段高 = 该类别在这个产区的条数，超过 6 类时尾部并成「其他类别」），柱顶金环 = 含国家级保护名录匹配，柱底橙环 = 含编辑口径濒危。尺寸、亮度、排序不映射任何字段，馆史页的诚实映射表里明确写出来。
- **钩子句**：`1186 个地方品种，你家的省份亮了几个？`（数字读自 `COLLECTION_SUMMARY`）。
- **四个镜头**（Tab，键盘可达，结论句随镜头同步）：
  | 镜头 | 视觉通道 | 结论口径 |
  | --- | --- | --- |
  | 全部分布 | 161 根产区柱按类别分段着色 | 1062 条记录聚成 161 个产区，落在 31 个省级行政区 |
  | 类别构成 | 强化类别色相 + 类别筛选条 | 同一类别在不同省份的分量并不平均 |
  | 国家级保护 | 命中的 271 个品种所在柱体点金 | 来自农业农村部第 940 号公告 |
  | 濒危之窗 | 编辑标注的 82 条所在柱体亮橙环 | 明确标注「非权威结论」 |
- **检索**：唯一的站内检索入口，输入 ≥2 字符直接跳到品种卷宗。
- **省份聚焦**：点省份按钮或直接点省块，展签栏切换为该省品种列表（带三级核验徽章），点条目进卷宗。
- **数据摘要**：`<details>` 折叠表格给出省级分布与类别构成，合计与 `COLLECTION_SUMMARY.total` 一致。
- **降级**：无 WebGL 时自动切到 2D 省域图（`ChinaMap`），HUD 也提供手动「平面图 / 立体图」切换。

### 4.2 互动厅（`/arcade`）

**总览页 + 三个子页**：`/arcade` 只做入口，列出三台展教装置的卡片（玩法、局数、数据边界、进场按钮），游客挑一台再进对应子页，避免三台装置挤在一屏里同时答题。

| 子页 | 装置 | 玩法 | 数据边界 |
| --- | --- | --- | --- |
| `/arcade/find-home` | 找家挑战 | 3 轮：给出品种名，在 8 个省份里点出真实产区；答错显示「方向不对：距真实产区约 N 公里」（haversine） | 只从 1062 条可落点记录出题 |
| `/arcade/identify` | 识图挑战 | 3 轮：看类别剪影选品种名，答完给出 3 个同类真实品种 | 剪影为项目手绘 SVG，不引用未经核验照片 |
| `/arcade/quiz` | 知识问答 | 5 题，四种题型循环（省份 / 类别 / 保护身份 / 濒危口径） | 出题只读已核验字段，末题附档案链接 |

- 三个子页顶部都有同一个切换条（`aria-current` 标当前装置），换装置不用退回总览；未知装置 id 自动回落到 `/arcade`。
- 总览页与子页脚注都写着「出题红线」：照片认品种模式因已核验本地图片为 0 张而**未启用**。
- 全部装置可用键盘完成（选项为真实 `button`，省份为可聚焦按钮组）。

### 4.3 品种卷宗（`/breed/:id`）

- 卷宗头部：编号 `BM-<ID>`、批次标签（第 N 批 / 2024 名录）、三级核验徽章、省份、类别、保护状态、别名。
- 正文复用 `BreedDetail`：体貌特征、生产性能、五维方向性雷达、文化故事。
- 页脚列出 `sourceIds` 命中的来源链与核验日期，并提供「2024 名录官方页面」与 PDF 回链。
- 不存在的 id 显示「档案未找到」并给出回光图入口。

### 4.4 馆史与来源（`/about`）

五个区块：建馆路线（6 步）、数据来源链（文件名 / 文号 / 发布日期 / 官方链接）、核验图例、**诚实映射表**、质量仪表盘、探索记录与 AI 使用披露、第三方许可（含 `china-map-3d (MIT)` 参考署名）。诚实映射表逐行说明「这个视觉通道对应哪个已核验字段」，并显式列出**不映射**的通道（尺寸、亮度、排序）。

### 4.5 404 页面

- 未匹配路由显示「页面未找到」，可一键返回光图。
- `/map`、`/encyclopedia`、`/dashboard`、`/compare`、`/pasture`、`/recommend`、`/ai`、`/home` 八条旧路由保留 `<Navigate replace>` 重定向到 `/`，旧书签不会 404。

## 七、数据与后端

### 7.1 品种数据

- 共 **1186 条站内记录**，存于 `src/data/`（基础库与 15 个扩充批次文件合并、2024 名录增量展开后运行时归一化）；其中 **1062 条**带可落点坐标，**124 条**省份待核验（不进入地图与省份统计）。
- 每条含展示字段：id、name、englishName、province、经纬度、category、endangered、appearance、performance、radar（方向性五维，可为空）、story、image。官方名称、别名、保护状态、核验日期等证据元数据由 `breedMetadata.ts` 按名称匹配第 940 号公告派生，不属于记录字段。
- 三级核验由 `src/data/verification.ts` 单点判定：`official`（命中第 940 号公告或 2024 名录来源）/ `pending`（省份待核验或坐标为哨兵）/ `editorial`（其余）。卷宗页与省份列表统一使用 `VerificationBadge` 呈现。
- 数据规范、批次记录与新增流程见 `docs/品种数据手册.md`；由「品种数据与手册同步」技能保证数据与手册一致。

## 八、国际化与主题

- **双语**：中文/英文一键切换，300+ 条文案键覆盖导航、各页面、品种详情、对比、看板图表标题、AI 助手、表单与提示语，界面文案全部经 `t()` 读取，切换语言时同步更新 `<html lang>`；品种数据内容（名称、故事等）与 AI 本地检索报告为中文资料。

## 九、响应式与无障碍

- 验收视口包括桌面 1440×900 和移动 390×844。
- 导航、抽屉、镜头 Tab、互动厅选项与省份按钮均可键盘操作，触控目标 ≥44px。
- 色彩对比度遵循 WCAG AA；信息不以颜色单独传达——保护身份用金色 + 文字标签、核验级别用徽章图标 + 文字。
- 3D 场景不是唯一入口：无 WebGL、低端机或系统「减少动态效果」时自动走 2D 省域图或静态帧，互动厅与卷宗页完全不依赖 3D。
- 离线提示使用非阻断状态消息；错误边界提供重新加载和返回光图。
- 页面级元信息按路由设置，标题层级和 404 语义保持独立。

## 十、使用指南（快速上手）

1. 打开 `/`，拖拽旋转 3D 光图，点底部四个镜头切换看法（注意每行结论句随镜头变化）。
2. 点「国家级保护」镜头看 271 个品种所在的柱体点金，或点「濒危之窗」看 82 条编辑标注所在的柱体亮起橙环（页面注明非权威结论）。
3. 点任意一根产区柱、或在顶部搜索框输入品种名，进入 **品种卷宗**——看体貌、性能、五维雷达，页脚有官方来源与 PDF 回链。
4. 去 `/arcade` 选一台装置进子页：找家挑战（答错会给「距真实产区约 N 公里」）、识图挑战、知识问答；子页顶部可随时换装置。
5. 去 `/about` 查来源链、诚实映射表、质量仪表盘与 AI 使用披露。

## 十二、视觉与版本沿革

界面采用宣纸米色、墨绿和克制的朱砂强调色，深色模式改用品牌墨绿体系；光图场景固定在近黑底上保证柱体对比。项目不再依赖远程字体，避免字体服务不可用或隐私请求带来的首屏风险。

- v1–v2：静态品种库 + 百科/地图/看板/对比。
- v3：五屏滚动叙事首页与热应激决策台（已下线，相关文件保留在 `src/components/effects/`）。
- v4（当前）：**「畜种光图」**——3D 中国光图 + 互动厅 + 品种卷宗 + 馆史页，导航收敛为 3 项，8 条旧路由重定向。

## 十三、配置、构建与部署

- 推荐 Node.js 20+ 与 pnpm。
- `pnpm dev` 启动本地开发；`pnpm build` 生成生产文件。
- `pnpm check` 运行类型、代码、测试、文档同步、构建和体积预算。
- `pnpm check:all` 额外构建无配置版本并运行桌面、移动端 E2E。
- `.env.example` 只列变量名和说明，真实密钥不得进入源码或文档。
