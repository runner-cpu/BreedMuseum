## 四、页面与功能详解

### 4.1 首页（`/`）

- **GalaxyBackground 星空背景**：Canvas2D 绘制，星点沿椭圆轨道缓慢旋转，密度为常规 3 倍，带闪烁效果与鼠标斥力交互。
- **SpotlightHero 主视觉**：聚光灯效果 + 中国地图（浅色基础图、70% 透明度、完整显示），滚动入场动画。
- **CircularGallery 类别画廊**：3D 旋转圆环展示 11 个畜禽类别卡片，支持拖拽/自动旋转。
- **MagicBento 功能区**：5 张功能入口卡片（品种地图、品种百科、数据看板、品种对比、AI 助手），带辉光、粒子与波纹交互效果。
- **ScrollFloat / ChromaGrid**：滚动文字浮动与彩色网格等视觉增强组件。

### 4.2 品种地图（`/map`）

- SVG 中国地图，按省份着色与品种计数标注。
- 点击省份联动品种列表；品种以坐标落点呈现（`pulseId` 脉冲高亮选中品种）。
- 点击落点/列表项打开 **BreedDetail 详情面板**：品种实拍图、外貌特征、生产性能、五维雷达图（产肉/产奶/繁殖/役用/适应性）、濒危等级、文化故事、来源说明与分享链接复制。

### 4.3 品种百科（`/encyclopedia`）

- 类别筛选（11 类）+ 关键词搜索：名称/别名/英文名优先命中，特征、性能与文化故事参与全文匹配（≥2 字符），名称命中排在全文命中之前。
- 卡片式列表展示品种缩略图、产地、濒危等级徽标，点击进入详情。

### 4.4 数据看板（`/dashboard`）

- 4 张统计卡：运行时记录总数（687）、覆盖省份、濒危/极危标记记录、普通记录。
- 6 组图表：各省品种数量 TOP15 柱状图（降序）、濒危等级构成、类别数量横向对比条、类别记录 Treemap、批次收录时间轴、各省品种密度热力图。
- 导出能力：看板导出 PNG 图片、数据导出 CSV 文件。

### 4.5 品种对比（`/compare`）

- 从百科/详情页加入对比（`compareIds`），多品种并排对比五维雷达与关键信息。
- 支持导出对比结果图片。

### 4.6 AI 助手（`/ai`）

四种工具模式，通过顶部工具栏切换；文本问答和报告支持无后端本地回退：

| 模式 | 说明 | 后端 |
| --- | --- | --- |
| 对话 | 基于本地品种库的规则路由、类别/省份/保护标记筛选 | 浏览器本地执行 |
| 报告 | 基于匹配记录生成 Markdown，并支持 PDF 导出 | 浏览器本地执行 |
| 生成图片 | 根据文字描述生成品种示意图 | 可选 AI 服务；未配置时显示引导 |
| 图片识别 | 上传 JPG / PNG / WebP 后匹配站内品种 | 可选 AI 服务；未配置时显示引导 |

- 快捷提问：3 个预设问题，移动端自动换行。
- 语音输入：录音后通过可选 AI 服务转写为文本；浏览器拒绝麦克风或未配置服务时保留清晰错误提示。
- 布局：对话区占满视口高度（减去顶栏），消息气泡最大宽度 75%，全宽容器与侧栏对齐。

### 4.7 404 页面

- 未匹配路由统一跳转，提示"页面未找到"，可一键返回首页。

## 七、数据与后端

### 7.1 品种数据

- 共 **687 条站内记录**，存于 `src/data/`（基础库与扩充批次文件合并后运行时归一化）。
- 每条含展示字段：id、name、englishName、province、经纬度、category、endangered、appearance、performance、radar（方向性五维，可为空）、story、image。官方名称、别名、保护状态、核验日期等证据元数据由 `breedMetadata.ts` 按名称匹配第 940 号公告派生，不属于记录字段。
- 数据规范、批次记录与新增流程见 `docs/品种数据手册.md`；由「品种数据与手册同步」技能保证数据与手册一致。

### 7.2 Edge Functions

| 函数 | 用途 |
| --- | --- |
| Edge Functions | 旧版托管能力保留在仓库，当前前端不调用，避免公开 anon key 驱动外部消费 |
| `kling-3-turbo-text-create` / `kling-3-turbo-query` | 可灵视频生成（已部署，当前 AI 助手界面未开放入口） |

## 八、国际化与主题

- **双语**：中文/英文一键切换，300+ 条文案键覆盖导航、各页面、品种详情、对比、看板图表标题、AI 助手、表单与提示语，界面文案全部经 `t()` 读取，切换语言时同步更新 `<html lang>`；品种数据内容（名称、故事等）与 AI 本地检索报告为中文资料。
- **主题**：浅色/深色/跟随系统三种模式；深色模式以降低阴影、提升表面亮度的方式呈现层次。

## 九、响应式与无障碍

- 桌面优先设计，768px 断点适配移动端；表格横向滚动、卡片等高铁律、触控目标 ≥48px。
- 色彩对比度遵循 WCAG AA；信息不以颜色单独传达（配图标与文字）。

## 十、使用指南（快速上手）

1. 打开首页，滚动浏览类别画廊与功能入口。
2. 进入「品种地图」，点击省份查看当地品种，点击落点查看详情并复制分享链接。
3. 进入「品种百科」按类别/关键词检索品种。
4. 在详情或百科中将品种「加入对比」，到「品种对比」查看雷达对比并导出。
5. 「数据看板」查看全局统计，可导出 PNG/CSV。
6. 「AI 助手」提问品种知识或生成报告。
7. 在 AI 助手中使用本地检索和报告导出，断网时仍可查询静态数据。

## 十一、维护指南

| 任务 | 方法 |
| --- | --- |
| 新增品种 | 遵循 `docs/品种数据手册.md` 第七节流程（查重→配图→新批次文件→注册→lint→同步手册），由 breed-data-manual-sync 技能强制约束 |

## 十二、版本沿革（摘要）

界面采用宣纸米色、墨绿和克制的朱砂强调色，深色模式改用品牌墨绿体系。项目不再依赖远程字体，避免字体服务不可用或隐私请求带来的首屏风险。

## 5. 移动端与无障碍

- 验收视口包括桌面 1440×900 和移动 390×844。
- 导航、抽屉、按钮和可点击密度格可使用键盘操作。
- 图表配有表格摘要，图片有替代文本，装饰图标不进入读屏顺序。
- 离线提示使用非阻断状态消息；错误边界提供重新加载和返回首页。
- 页面级元信息按路由设置，标题层级和 404 语义保持独立。

## 6. 数据来源与版权

第 940 号公告用于核对 271 个畜禽名称和国家级保护名录身份。公告不支持将这些名称直接解释为“濒危”，也不支持推导五维分值。历史叙述、点位和图片仍需逐条核验；图片索引中统一使用“历史外链；来源权利待核验”或“项目 SVG 占位”。在取得作者与明确授权前，不应宣传图片可自由复用。

## 7. 配置、构建与部署

- 推荐 Node.js 20+ 与 pnpm。
- pnpm dev 启动本地开发；pnpm build 生成生产文件。
- pnpm check 运行类型、代码、测试、文档同步、构建和体积预算。
- pnpm check:all 额外构建无配置版本并运行桌面、移动端 E2E。
- .env.example 只列变量名和说明，真实密钥不得进入源码或文档。
- HashRouter 适合静态托管；缺点是 URL 带 #，搜索引擎抓取能力有限。
- GitHub Pages 同时发布 /audit/ 审计报告与品种图片索引（breed-images.csv）、/privacy.html 隐私说明（含"图片来源与版权状态"章节）、robots.txt、sitemap.xml 和四个原创 SVG；部署前应运行 pnpm build:pages 并检查这些静态地址返回 200。
- 数据版本 2026-09-27 表示馆藏快照与来源核对版本；本说明书/审计日期 2026-10-02 表示文档和工程复核日期。

## 8. 已知限制

- 蜂和蚕尚未进入现有五维数据模型。
- 大量历史图片、故事、点位与五维值缺乏逐条可审计出处。
- 单页应用与 HashRouter 的 SEO 能力有限，关键内容仍依赖客户端渲染。
- breeds 数据块较大，后续可按类别或地区拆分加载。
- 英文界面仍以关键导航词条为主，内容数据并未完成专业双语审校。
- 最新 Vitest 已通过 28 个测试文件、83 项测试；Playwright 双视口共 24 个用例，23 项通过、1 项按桌面条件跳过、0 项失败。
