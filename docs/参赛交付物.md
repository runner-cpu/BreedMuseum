## 二、作品说明（一页，可转 PDF）

**作品名称**：高原畜禽种质资源数智服务平台（中国地方畜禽品种数字博物馆 · 青海专版）

**一句话简介**：一个纯前端、零后端、零 API 费用的种质资源科普与决策平台——把温湿指数（THI）热应激模型、品种适应性规则引擎与国家名录数据全部搬进浏览器。

**解决的问题**

1. 高原热应激管理工具缺位：牧区普遍依赖经验判断放牧时段，缺少因地制宜的量化工具；本作品将 THI 模型与牦牛/藏羊等七个畜种阈值封装为开箱即用的决策台，并直接嵌进首页叙事。
2. 种质资源信息散落：名录 PDF、普查公告、地方志分散在各处；本作品建立可检索、可对比、来源可溯的数字化馆藏（1186 条，含 2024 名录全量增量核对）。

**技术要点**

- React + TypeScript + Vite + Tailwind，全部静态构建，托管于 GitHub Pages；
- 首页五屏滚动叙事（`motion` 的 `useScroll`/`useTransform` + 原生 SVG，零重型依赖），滚动效果全部带 `prefers-reduced-motion` 直显分支；
- THI 公式 `THI = T − (0.55 − 0.55×RH)(T − 14.5)` + 海拔（2000m 起每千米 −1.2，封顶 −3.6）与畜龄修正；
- 推荐引擎：海拔区间 × 养殖目的 × 饲养模式三维规则库（50+ 高原品种），0–100 分评分与逐条理由；
- 数据治理：官方 PDF 逐页人工核对生成全量台账，权威校验测试覆盖；11 类诊断的数据审计、123 项单元测试、36 项浏览器端到端用例；
- 隐私友好：无账号、无追踪、计算本地化。

**差异化**

1. 所有知识点可溯源到官方文件的逐条核验渠道，而不是"网上搜来的"；首页叙事只用能自证的站内数据，不引用查无出处的行业数字；
2. 决策工具即开即用，面向牧民的离线使用场景（无需登录/联网），且是首页故事线的一部分而不是藏在二级页；
3. 数据与文档一致性由自动化门禁保证（`docs:check` 在 CI 中强制）。

## 三、答辩提纲（8 分钟，含预期问题）

**1. 为什么选高原畜禽？（1 分钟）**
三江源是牦牛、藏羊的演化中心；青藏高原 66 个地方品种中已有 13 个列入国家级保护名录（青海 7、西藏 6）。种质资源一旦消失不可再生，而现有工具大多面向实验室，牧民可用的数字化决策工具几乎空白。

**2. 核心技术演示（3 分钟）**
现场演示：首页五屏叙事（重点屏③内嵌决策台的滑杆联动与场景预设）、屏④ 66/13 地图金星、推荐引擎（三项决策路径拆解）、名录来源链（详情页点官方链接）。

**3. 数据从哪来、可信度如何保证？（1.5 分钟）**
农业农村部第 940 号公告 + 国家畜禽遗传资源委员会《名录（2024 年版）》官方 PDF（文号：畜资委办〔2025〕18 号）。官方 PDF 逐页核对建立机器可读台账：1129 条全部落位（畜禽 1090 + 蜂 39，含引入品种/配套系 171 条与蚕 307 条按口径明确排除），范围内 958 条与运行时 1186 条名称逐一对账，台账文件与数据审计测试共同防止回归。

**4. 与"大模型方案"的区别？（1.5 分钟）**
本作品刻意不依赖大模型：规则透明、结果可复现、零 API 费用、离线可用、无隐私外传。对生产决策类工具而言，可解释性和可用性优先于生成能力。

**5. 预期提问速答（1 分钟）**

- *THI 阈值有依据吗？* 阈值分档参考高原畜牧热应激文献的常用口径，页面上明确标注"教学演示口径，不替代兽医指导"，并给出公式与修正项来源。
- *首页为什么只有 66 和 13 两个数字？* 首页叙事坚持"站内自证"：这两个数都能从馆藏数据与 940 号公告名单直接算出；编辑口径的濒危标签属于主观标注，只在数据看板展示并注明口径。
- *图片版权？* 三类来源分级标注：已核验授权本地镜像 / 项目原创 SVG（518）/ 历史外链待核验（668）；隐私页逐类说明，并开放勘误渠道。
- *能推广到其他畜种/地区吗？* 规则库与阈值表是数据驱动的（`src/data/pastureThi.ts`、`breedRecommend.ts`），增加畜种只需扩充配置，代码无需改动。
- *手机能用吗？* 全部页面适配 390px 移动视口，E2E 门禁包含移动端场景。
