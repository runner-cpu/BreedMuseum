# 参赛交付物（数字媒体科技作品 · 网页/信息可视化方向）

> 本文件是提交前需要使用的三件套工作稿：3 分钟演示视频脚本、作品说明、答辩提纲。
> 所有数字均与站内运行时数据一致（馆藏 1186 条 / 带图可浏览 667 条 / 可落点 1062 条 / 待核验省份 124 条 / 940 号公告匹配 271 / 编辑口径濒危 82），口径以 `COLLECTION_SUMMARY` 与 `/dashboard` 的数据覆盖说明为事实源。地图实际绘制的是 667 条带图记录 → 154 个产区、30 个省级行政区；1062 / 161 是全量口径，只在文档与覆盖度图表中引用。
> 首页口径：钩子句「1186 个地方品种，你家的省份亮了几个？」，视觉通道只映射已核验字段。

## 二、作品说明（一页，可转 PDF）

**作品名称**：中国地方畜禽品种数字博物馆 ·「地图探索」

**一句话简介**：把一份 46 页的官方名录 PDF，变成一张可以直接读懂的 2D 数据地图——667 条带图地方品种记录聚成 154 个产区点位、覆盖 30 个省级行政区，省块色阶表达分布，点任意一处都能打开百科详情并查看数据边界。

**解决的问题**

1. **官方资源查得到但看不进去**：名录 PDF、普查公告、地方志分散在各处，公众缺少愿意停留的入口。本作品把 1186 条馆藏映射到地理坐标上，用"你家的省份亮了几个"把地域认同接上数据。
2. **数据可信度无从判断**：绝大多数同类站点把权威数据、编辑推断和待核验项混在一起展示。本作品建立三级核验状态（官方/编辑/待核验）与数据边界说明，逐条说明每个数字和视觉通道的证据级别。

**技术要点**

- React 18 + TypeScript + Vite + Tailwind，全部静态构建，托管于 GitHub Pages，无运行时后端；
- **2D 地图**：SVG 省域图 + 产区点位聚合；667 条带图记录按「同省、平面距离 ≤ 0.22」聚成 154 个产区，省块按已核验记录数映射色阶，点位对应真实坐标，镜头筛选国家级保护（252 条）和编辑口径濒危（82 条）；
- **交互与无障碍**：开场按省份依次点亮，镜头与类别为两组 `aria-pressed` 按钮、省份为按钮、互动厅全部键盘可玩；系统开启「减少动态效果」时直接呈现静态帧；
- **数据管线**：通用地理聚合模块把产区聚合与镜头过滤固化为纯函数测试；批次归属由 `tasks/generate-breed-batch.mjs` 确定性生成并带 `--check`；
- **数据治理**：官方 PDF 逐页核对生成全量台账，权威校验测试覆盖；11 类诊断的数据审计、161 项单元/组件测试、35 个浏览器端到端用例（桌面/移动双视口共 70 项运行，移动导航用例按条件跳过）；
- **隐私友好**：无账号、无追踪、无第三方 AI 调用，全部计算本地化。

**差异化**

1. **单一受众做到底**：不像"既科普又决策"的双定位站点，本站唯一受众是好奇的人，唯一钩子是一个可以玩起来的地理问题；
2. **可查证优先于好看**：宁可让互动厅少开一个模式（照片认品种因 0 张已核验照片而关闭），也不拿来源不明的素材充当展品；
3. **工程数字有契约**：几何、统计、批次、出题范围都由测试与审计守住，文档与代码同步校验（`docs:check` 在 CI 中强制）。

## 三、答辩提纲（8 分钟，含预期问题）

**1. 为什么做这个选题？（1 分钟）**
《国家级畜禽遗传资源保护名录》（农业农村部公告第 940 号）收录 271 个畜禽品种，2024 名录更进一步收录 1129 条资源，但这些数字对公众几乎不可见。我们判断瓶颈不是"没有数据"，而是"没有入口"。所以第一个决定就是：不做又一个可检索的表格，做一座让人愿意先看见、再去查证的光图。

**2. 核心技术演示（3 分钟）**
现场演示：地图点位与「全部落点 / 国家级保护 / 濒危之窗」镜头切换（重点演示「国家级保护」252 条可浏览记录的筛选，以及与类别筛选的叠加）、点一个点位打开百科详情面板、互动厅答错一题看距离反馈、数据看板滚动查看覆盖度与统计口径。

**3. 数据从哪来、可信度如何保证？（1.5 分钟）**
农业农村部第 940 号公告 + 国家畜禽遗传资源委员会《名录（2024 年版）》官方 PDF（文号：畜资委办〔2025〕18 号）。官方 PDF 逐页核对建立机器可读台账：1129 条全部落位（畜禽 1090 + 蜂 39，含引入品种/配套系 171 条与蚕 307 条按口径明确排除），范围内 958 条与运行时 1186 条名称逐一对账。运行时 1186 条中 1062 条带可用坐标、124 条省份待核验——**这 124 条不进入地图和省份统计，但仍在百科中可检索并标注待核验**，这是我们主动选择的保守口径。

**4. 为什么选择 2D？（1.5 分钟）**
2D 在本作品里只承担一件事：让"位置"和"证据边界"能被所有设备直接看见。所以：省块色阶映射的是该省已核验记录量，产区点位映射真实经纬度（同省相邻坐标聚成产区），镜头筛选映射保护匹配与编辑标注。点位的选中颜色、尺寸和排序属于交互提示，不映射额外事实；数据看板和项目文档公开说明这些边界。收敛为 2D 后，全部设备拿到同一份完整信息密度。

**5. 预期提问速答（1 分钟）**

- *和同类地图可视化比，差异在哪？* 同类作品通常在地图上按省份上色或用飞线；本作品把每条可落点记录聚合到真实产区坐标（带图记录 667 条 → 154 个点位；全量口径 1062 → 161），点位可直接打开百科详情，且地图镜头、筛选和显示边界都写成可测试的数据函数，让视觉叙事和证据口径保持一致。
- *为什么有些记录只有 124 条待核验不显示在地图上？* 坐标未知时我们不用 `(0,0)` 当有效落点（那会在中国中部伪造一个热点），也不用省份猜坐标。这 124 条保留在馆藏里、可检索、百科详情可读，只是不进地图与省份统计。
- *图片版权？* 三类来源分级标注：已核验授权本地镜像（目前 0 张）/ 项目原创 SVG（519）/ 历史外链待核验（667）；隐私页逐类说明，`/audit/breed-images.csv` 逐条公开状态，并开放勘误渠道。互动厅的「照片认品种」模式因没有已核验照片而**未启用**，页面公示了这个决定。
- *濒危标签权威吗？* 不权威，是我们主动标注为「编辑口径」的 82 条，页面上写"非权威结论"。这也是为什么首页钩子句用 1186（可证明的记录数）而不是濒危数字。
- *手机能用吗？* 全部页面适配 390px 移动视口，E2E 门禁包含移动端场景；2D SVG 地图按需渲染产区点位，系统减动效时直接走静态帧，互动厅与百科详情面板共用同一套轻量交互。
