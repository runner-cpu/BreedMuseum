# 参赛交付物（数字媒体科技作品 · 网页/信息可视化方向）

> 本文件是提交前需要使用的三件套工作稿：3 分钟演示视频脚本、作品说明、答辩提纲。
> 所有数字均与站内运行时数据一致（馆藏 1186 条 / 可落点 1062 条 / 待核验省份 124 条 / 940 号公告匹配 271 / 编辑口径濒危 82），口径以 `COLLECTION_SUMMARY` 与 `/about` 的诚实映射表为唯一事实源。
> 首页口径：钩子句「1186 个地方品种，你家的省份亮了几个？」，视觉通道只映射已核验字段。

## 二、作品说明（一页，可转 PDF）

**作品名称**：中国地方畜禽品种数字博物馆 ·「畜种光图」

**一句话简介**：把一份 46 页的官方名录 PDF，变成一座可以拖着转的 3D 中国——1062 条地方品种记录聚成 161 个产区的发光光束，束身按类别分段，点任意一道都能顺着来源链回到官方文件。

**解决的问题**

1. **官方资源查得到但看不进去**：名录 PDF、普查公告、地方志分散在各处，公众缺少愿意停留的入口。本作品把 1186 条馆藏映射到地理坐标上，用"你家的省份亮了几个"把地域认同接上数据。
2. **数据可信度无从判断**：绝大多数同类站点把权威数据、编辑推断和待核验项混在一起展示。本作品建立三级核验徽章（官方/编辑/待核验）与「诚实映射表」，逐条说明每个数字、每个视觉通道的证据级别。

**技术要点**

- React 18 + TypeScript + Vite + Tailwind，全部静态构建，托管于 GitHub Pages，无运行时后端；
- **3D 光图**：Three.js + `@react-three/fiber`；省域 SVG 经自研管线（解析 → 面积过滤 → 质心孔洞判定 → 挤出）转为几何，1062 条落点记录先按「同省、世界距离 ≤ 0.22」聚成 161 个产区，每个产区一道按类别分段的细长自发光光束（束身合并进同一个 `InstancedMesh`，束根 / 束顶各一层径向光晕，束顶金环 / 束底橙环各一层环面）；**零后处理、零 HDR**，`dpr` 上限 2，相机补间为手写 lerp；
- **降级与无障碍**：探测无 WebGL 或系统开启「减少动态效果」时自动回落 2D 省域图，镜头为 Tab、省份为按钮、互动厅全部键盘可玩；
- **数据管线**：`src/lib/geo3d/__tests__/geometry.test.ts` 把实测几何数字（329 子路径 / 282 噪声环 / 47 环 / 2875 点 / 澳门退化）固化为回归契约；批次归属由 `tasks/generate-breed-batch.mjs` 确定性生成并带 `--check`；
- **数据治理**：官方 PDF 逐页核对生成全量台账，权威校验测试覆盖；11 类诊断的数据审计、177 项单元/组件测试、27 个浏览器端到端用例（桌面/移动双视口共 54 项运行）；
- **隐私友好**：无账号、无追踪、无第三方 AI 调用，全部计算本地化。

**差异化**

1. **单一受众做到底**：不像"既科普又决策"的双定位站点，本站唯一受众是好奇的人，唯一钩子是一个可以玩起来的地理问题；
2. **可查证优先于好看**：宁可让互动厅少开一个模式（照片认品种因 0 张已核验照片而关闭），也不拿来源不明的素材充当展品；
3. **工程数字有契约**：几何、统计、批次、出题范围都由测试与审计守住，文档与代码同步校验（`docs:check` 在 CI 中强制）。

## 三、答辩提纲（8 分钟，含预期问题）

**1. 为什么做这个选题？（1 分钟）**
《国家级畜禽遗传资源保护名录》（农业农村部公告第 940 号）收录 271 个畜禽品种，2024 名录更进一步收录 1129 条资源，但这些数字对公众几乎不可见。我们判断瓶颈不是"没有数据"，而是"没有入口"。所以第一个决定就是：不做又一个可检索的表格，做一座让人愿意先看见、再去查证的光图。

**2. 核心技术演示（3 分钟）**
现场演示：光图自转与四镜头切换（重点演示「国家级保护」271 个品种所在光束点金与结论句同步）、点一道产区光束进品种卷宗并点开官方 PDF、互动厅答错一题看距离反馈、馆史页滚动诚实映射表。

**3. 数据从哪来、可信度如何保证？（1.5 分钟）**
农业农村部第 940 号公告 + 国家畜禽遗传资源委员会《名录（2024 年版）》官方 PDF（文号：畜资委办〔2025〕18 号）。官方 PDF 逐页核对建立机器可读台账：1129 条全部落位（畜禽 1090 + 蜂 39，含引入品种/配套系 171 条与蚕 307 条按口径明确排除），范围内 958 条与运行时 1186 条名称逐一对账。运行时 1186 条中 1062 条带可用坐标、124 条省份待核验——**这 124 条不进入地图和省份统计，但仍在卷宗页可查并标⏳**，这是我们主动选择的保守口径。

**4. 3D 是不是炫技？（1.5 分钟）**
3D 在本作品里只承担一件事：让"位置"这个真实字段能被直接看见。所以：省块高度映射的是该省馆藏量（四分位四档），光束的平面位置映射的是真实经纬度（同省相邻坐标聚成产区），光束粗细与高度映射这个产区的品种数，束身分段色相映射类别构成，束顶金环映射第 940 号公告身份，束底橙环映射编辑口径濒危。馆史页的诚实映射表还显式列出**不映射**的通道——尺寸（已由记录数占用）、亮度、排序——避免观众从视觉大小反推不存在的结论。技术上零后处理、零 HDR，无 WebGL 时回落 2D 图，不是"为了 3D 而 3D"。

**5. 预期提问速答（1 分钟）**

- *和同类地图可视化比，差异在哪？* 同类作品通常在地图上按省份上色或用飞线；本作品把每条记录落到真实产区坐标（1062 条 → 161 个产区），产区光束还能按住户「分段」读出类别构成，且每道光束都能钻进卷宗、追到官方 PDF。工程上参考了 `dora-ljh/china-map-3d`（MIT）的坐标约定与预算纪律，但数据、几何管线、材质与交互均为自研，已在馆史页署名。
- *为什么有些记录只有 124 条待核验不显示在地图上？* 坐标未知时我们不用 `(0,0)` 当有效落点（那会在中国中部伪造一个热点），也不用省份猜坐标。这 124 条保留在馆藏里、可检索、卷宗页可读，只是不进地图与省份统计。
- *图片版权？* 三类来源分级标注：已核验授权本地镜像（目前 0 张）/ 项目原创 SVG（518）/ 历史外链待核验（668）；隐私页逐类说明，`/audit/breed-images.csv` 逐条公开状态，并开放勘误渠道。互动厅的「照片认品种」模式因没有已核验照片而**未启用**，页面公示了这个决定。
- *濒危标签权威吗？* 不权威，是我们主动标注为「编辑口径」的 82 条，页面上写"非权威结论"。这也是为什么首页钩子句用 1186（可证明的记录数）而不是濒危数字。
- *手机能用吗？* 全部页面适配 390px 移动视口，E2E 门禁包含移动端场景；3D 场景把设备像素比上限压到 2（避免高分屏上无收益的渲染开销），1,062 条落点记录聚成 161 道产区光束以压低 draw call；减动效设备直接走静态帧或 2D 省域图，互动厅与卷宗页完全不依赖 3D。
