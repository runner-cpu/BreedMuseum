# 首页滚动叙事重构实施计划（v1.0 · 执行稿）

> 决策基线（用户已确认）：
> 1. **数据叙事走"站内自证"路线**——不使用外部查无出处的行业数字（变暖 2 倍 / 华美牧场 11% / 小月山 90% 均已核验为无出处）；
> 2. **首页全屏重写为 5 屏滚动叙事**（保留可复用的 SpotlightHero / 精选卡 / 地图金星）；
> 3. **导航精简为 4 项，其余路由保留可直连**，仅收起入口。
>
> 数据快照：运行时 1186 条；高原 66（青海 28 + 西藏 38）；940 号公告青藏精确命中 **13**（青海 7 + 西藏 6，与 `COLLECTION_SUMMARY.plateauNationalProtected` 一致）。
> 目标工期：6–7 天（不含录制/答辩材料）。

## 0. 一句话目标

首页从"门户导航"变成**一条 5 屏讲完的故事线**：看见问题 → 理解量化 → 当场用工具 → 看见家底 → 拿到行动号召；30 秒滚完即理解"乡村振兴在干嘛"。

## 2. 五屏分镜（最终稿）

### 屏① 痛点（镜头：夜色草原 + 牦牛剪影 + 热浪上涌）

- **文案（zh）**：主标题"高原的夏天，正在变热"；副标"牦牛和藏羊适应了严寒，却越来越难躲开热应激——一种看不见、摸不着、但真实影响采食与产奶的压力。"
- **英文**：`Highland summers are getting hotter` / `Yak and Tibetan sheep are built for cold — heat stress is a pressure they were never adapted to.`
- **视觉**：全屏深蓝夜空渐变（`#0b1220 → #1a2438`）→ 滚动进入时向暖橙（`#3a2418`）过渡；底部高原草原 SVG 剪影；居中牦牛剪影 SVG（项目原创，新文件 `plateau-herd-scene.svg`）。
- **动效**：`useScroll` 驱动背景色温变化 + 剪影视差上移；reduced-motion 下静态渐变色（暖橙中性）。
- **数据**：无数字（避免不可辩护陈述）。

### 屏② 量化（镜头：THI 曲线爬升，越过牦牛红线）

- **文案**：主标题"热应激不是感觉，是可以算出来的"；副标"我们用温湿指数 THI 把它变成一条曲线——当它越过红线，牦牛的采食、增重与产奶就开始付出代价。"
- **公式行**：`THI = T − (0.55 − 0.55×RH)(T − 14.5)`（等宽字体，可展开"模型说明"）
- **视觉**：单色描边曲线图（x=气温 5→35℃，y=THI），湿度固定 60%；四条牦牛阈值横线（19/23/26/35，标注 舒适 / 警戒 / 危险 / 极端），色带与决策台一致（绿/黄/橙/红）。
- **动效**：滚动进度驱动 `stroke-dashoffset` 绘制曲线，越过每条阈值线时该线高亮一次；reduced-motion 下曲线完整显示。
- **数据**：曲线由 `src/data/pastureThi.ts` 的 `evaluateThi()` 实时计算生成（32 个采样点），**不是手画曲线**——页面上注明"THI 模型曲线 · 湿度固定 60% · 畜种：牦牛"。

### 屏③ 工具（核心：THI 决策台内嵌，全站唯一"能动手"的屏）

- **文案**：主标题"拖一下滑杆，答案立刻出现"；副标"选畜种、给温度湿度，决策台当场给出热应激等级和三条可以马上执行的管理动作——全部在你的浏览器里计算。"
- **组件**：复用并抽出 `ThiConsolePanel`（共享组件）：
  - 输入：畜种（7 种）、温度（滑杆 + 数字）、湿度、海拔、畜龄；
  - 输出：大 THI 数字（Tabular Nums）+ `GradeBar` 四级色带 + `ThiGauge` 仪表 + **三条优先管理动作**编号卡；
  - 场景预设按钮（3 个）：`玉树夏季 32℃ / 湿度 45% / 海拔 4200m / 牦牛`、`环湖草原 28℃ / 55% / 3200m / 藏羊`、`柴达木 35℃ / 25% / 2800m / 骆驼`；
  - 底部链接："打开完整决策台 →"（`/pasture`，带 query 预填）。
- **动效**：滑杆联动背景色温；数字使用 `CountUp`（遵守 C1 兜底契约）；reduced-motion 无过渡、直显。
- **无障碍**：滑杆 `aria-label`、色带 `role="img"` aria-label、建议区 `aria-live="polite"`（沿用现有实现）。

### 屏④ 家底（镜头：中国地图聚光 + 金星依次点亮）

- **文案**：主标题"66 个高原家底，13 颗国家级保护星"；副标"青藏高原共收录 66 个地方品种（青海 28 / 西藏 38），其中 13 个列入农业农村部第 940 号公告国家级保护名录。"
- **数字卡（两个，滚动计数）**：`66`（青藏高原品种，副标"青海 28 + 西藏 38"）；`13`（国家级保护品种，副标"农业农村部公告第 940 号"，url → `/map`）。
- **视觉**：复用 `SpotlightHero` 的聚光地图原理（`provincePaths` + 径向遮罩），但**聚焦青藏**：初始全国低透明，滚动进入时高原省份提升饱和度，13 颗金星按 geographic 顺序依次点亮（`protected-pulse` 动画延迟错峰）。
- **动效**：地图从"模糊/低透明 → 聚焦"由`useScroll`进度驱动；金星点亮可用 CSS animation-delay 实现，无需 JS 定时器 → reduced-motion 下全部常亮。
- **文案边界**：不出现"濒危 9"（编辑口径只保留在看板，并标注"编辑标签口径"）。

### 屏⑤ 行动（镜头：全屏金色微光 + CTA）

- **文案**：主标题"用数据守护高原牧民的每一次转场"；副标"热应激预警工具、种质地图与品种百科，现在就能用——离线可用、无需登录。"
- **CTA 三入口卡**（复用现有三入口卡样式 + SVG 预览）：热应激预警（`/pasture`）、种质地图（`/map`）、品种百科（`/encyclopedia`）。
- **页脚**：保留现有 Footer（数据来源、更新日志）但**移出首页叙事流**，作为常规页脚；同时在全站 Layout 保留页脚。
- **动效**：金色径向微光渐显；reduced-motion 静态。

## 8. 风险与回滚

| 风险 | 缓解 |
|---|---|
| 滚动驱动的 sticky 在移动端 Safari 抖动 | 屏③ 面板用"滚到即固定"的 `position: sticky` 最小实现；真机走查列入 D6 |
| 曲线组件性能（32 采样点 + 4 线） | 纯静态 SVG path，`useTransform` 只驱动 `strokeDashoffset`；无逐帧重渲染 |
| 叙事屏改动导致首屏包体增长 | 屏③ 面板代码拆独立 chunk（`React.lazy` + `Suspense`）或在首屏后 `import()`；`bundle:check` 守护 |
| E2E 断言漏改导致部署被门禁挡住 | D6 强制 `pnpm check:all`；C6 已在约束表 |

**回滚**：五屏组件与导航改动集中在 2 个提交（"feat(home): scrollytelling screens" / "feat(nav): four-item navigation"），回滚即 revert 这两个提交，数据层与其余路由零影响。
