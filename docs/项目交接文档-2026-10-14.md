# BreedMuseum 项目交接文档

远端仓库：https://github.com/runner-cpu/BreedMuseum

## 1. 项目定位与当前路线

BreedMuseum 是一个面向公众的高原畜禽品种数字博物馆。项目以可追溯馆藏数据为核心，提供品种百科、产区地图、热应激决策台、数据看板和推荐等入口；公开站点部署在 GitHub Pages，源码以 `main` 分支为准。

本轮采用用户确认的 **C「沉浸实验」**方向：保留高对比中国地图和聚光揭示，强化滚动叙事、镜头转场、悬停/按压反馈，同时保持数据可追溯、移动端可用和 `prefers-reduced-motion` 降级。

当前实际完成的是首页的沉浸式地图基线，不是完整的“五屏滚动叙事”。完整五屏方案仍以 [`docs/首页滚动叙事重构计划.md`](./首页滚动叙事重构计划.md) 为下一阶段执行依据。

## 2. 本轮已经完成的改动

首页当前结构为：

1. 聚光中国地图英雄区；
2. “参观动线”入口：地图探索、品种百科、数据看板；
3. 精选品种记录横向浏览；
4. 馆藏指标区：总记录、覆盖省份、畜禽类别、保护匹配；
5. 按畜种浏览。

交互和动效包括：

- 地图英雄区使用 Motion `useMotionValue`、`useSpring`、`useScroll`、`useTransform`，鼠标移动驱动聚光，内部 `main` 滚动驱动地图缩放、上移、透明度和标题淡出；
- 触屏设备不依赖鼠标聚光，改为静态彩色地图，避免触控端出现不可操作的“跟随光标”假象；
- 页面下方模块使用 `Reveal` 做进入视口显现，并在 reduced-motion 下直显；
- 移动端标题、搜索框、入口按钮和指标布局已做单列/窄屏适配；
- 所有首页统计继续读取 `COLLECTION_SUMMARY`，没有新增独立统计口径。

## 3. 文件职责

| 文件 | 本轮职责 | 接手时注意 |
|---|---|---|
| `src/components/effects/SpotlightHero.tsx` | 聚光地图、指针弹簧、滚动镜头和英雄文案 | `useScroll` 绑定应用内部 `main`；修改滚动容器前要复测标题和地图变换 |
| `src/pages/LightMapPage.tsx` | 首页模块顺序、`Reveal`、入口跳转、精选记录、统计和类别浏览 | 数据必须继续从 `COLLECTION_SUMMARY` / 现有数据派生，不要在 JSX 写新的统计数字 |
| `src/index.css` | 全局展厅令牌、基础响应式规则和其他页面样式 | 首页专属规则已拆到 `src/styles/light-map-page.css`；修改全局样式后重新检查 CSS 预算 |
| `src/styles/light-map-page.css` | 首页懒加载的沉浸式布局、地图聚光和移动端规则 | 该文件随首页路由加载，用于控制全局 CSS 包体；新增首页样式优先放这里 |
| `src/components/layouts/Layout.tsx` | 首页 `main` 增加 `relative`，让 Motion 正确计算内部滚动容器 | 不要把应用滚动容器改成 `window`，除非同步修正 E2E 和滚动逻辑 |
| `docs/首页滚动叙事重构计划.md` | 下一阶段五屏叙事的决策和验收基线 | 该文档是计划，不代表五屏已实现 |

本轮未改路由、馆藏数据、数据字段或现有页面的功能契约。

## 6. 推荐执行顺序

### P0：接手并固定当前基线

1. 先审阅本次五个代码文件，确认地图滚动、触屏降级和 reduced-motion 行为符合预期。
2. 在本地执行 `pnpm check:all`；如果门禁通过，提交并推送当前基线。
3. 在 GitHub Actions 中确认该提交的 quality 和 Pages deploy 均成功，再开始下一批视觉改动。

### P1：推进五屏滚动叙事

按 [`docs/首页滚动叙事重构计划.md`](./首页滚动叙事重构计划.md) 的顺序执行：

1. 先抽取可复用的 `ThiConsolePanel`，让首页和 `PasturePage` 共用同一套计算、等级色带、仪表和管理建议。
2. 实现屏①痛点和屏② THI 曲线；曲线必须由 `evaluateThi()` 采样生成，不能手画或写死路径。
3. 实现屏③决策台内嵌、场景预设和键盘/触屏交互。
4. 实现屏④青藏高原聚焦地图与保护名录金星，再实现屏⑤行动 CTA。
5. 最后再精简导航、补齐中英文词典和跨页面入口，避免导航改动遮蔽核心交互回归。

### P2：补齐回归保护和发布质量

- 增加滚动镜头、390px 移动端、reduced-motion 和首页三入口的 E2E；
- 为 `ThiConsolePanel`、THI 曲线采样和 `CountUp` 滚动触发补充有行为价值的测试；
- 处理 `breeds` 大 chunk 和完整 `pnpm check:all` 门禁；
- 五屏上线后再单独开数据质量批次，不要把分类修复、精选故事重写和首页视觉改版混在同一个提交中。

## 7. 不应破坏的约束

- 不删除或改写现有路由，`/recommend`、`/dashboard`、`/compare`、`/ai` 等页面仍需可直连；
- 不改变 `COLLECTION_SUMMARY` 的统计口径，页面统计统一从该常量或明确的数据派生函数读取；
- 所有滚动、悬停和转场都必须有 `prefers-reduced-motion` 的静态终态；
- 保持移动端键盘可达、触屏可用，交互目标至少满足现有项目的触控尺寸要求；
- 不新增 Three.js、GSAP 或其他重型依赖，本项目现有 Motion 能覆盖滚动和转场需求；
- 中英文文案键必须成对维护；
- 不把外部无法核验的行业数字写入首页；
- 发布前必须执行 `pnpm check:all`，质量门禁失败时不要绕过 Actions 手动发布。
