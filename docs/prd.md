# 需求文档

## 1. 应用概述

### 1.1 应用名称
中国地方畜禽品种数字博物馆

### 1.2 应用描述
面向公众和畜牧专业学生的中国地方畜禽品种科普展示平台，通过可视化地图、分类浏览与AI智能助手，展示我国丰富的畜禽品种资源及其文化故事。

## 2. 用户与使用场景

### 2.1 目标用户
- 动物科学专业学生
- 畜牧从业者
- 科普爱好者

### 2.2 核心使用场景
- 学生通过地图和分类浏览了解中国地方畜禽品种的地理分布和特征
- 从业者查询特定省份或类别的畜禽品种信息
- 科普爱好者阅读品种文化故事，了解畜禽品种的历史背景
- 用户通过AI助手快速获取品种问题解答、生成报告、识别图片
- 用户收藏感兴趣的品种，建立个人品种库
- 用户对比多个品种的特征与性能
- 用户随机探索品种，发现新的畜禽资源

## 3. 页面结构与功能说明

### 3.1 页面结构

```
中国地方畜禽品种数字博物馆
├── 顶部导航栏
├── 左侧导航栏（首页除外）
├── 主体内容区
│   ├── 首页（品牌展示页）
│   ├── 品种地图页
│   │   ├── 中国地图组件
│   │   └── 品种详情卡片
│   ├── 数据看板页
│   ├── 品种百科页
│   ├── AI助手页
│   │   ├── 紧凑工具栏（模式切换）
│   │   ├── 推荐问题卡片区
│   │   ├── 对话流展示区
│   │   └── 单行输入区
│   ├── 用户中心页
│   │   ├── 我的收藏
│   │   ├── 个人信息
│   │   └── 退出登录
│   └── 品种对比页
├── 登录/注册页
└── 底部页脚
```

### 3.2 顶部导航栏
- **导航入口**：首页、品种地图、数据看板、品种百科、AI助手
- **功能控件**：搜索框、主题模式切换（浅色/深色/跟随系统）、语言切换（简体中文/English）、用户状态区（未登录显示登录/注册，已登录展示头像与下拉菜单）
- **样式**：深绿色(#1a3a2a)背景，米白色(#f5f0e8)文字

### 3.3 左侧导航栏
- **显示规则**：首页隐藏，其余页面显示
- **导航项**：11个类别（猪、牛、羊、鸡、鸭、马、骆驼、兔、鹅、鸽、其他），配置独立SVG线性图标与专属标识色
- **交互**：支持与主内容区/地图点位双向联动筛选与高亮定位

### 3.4 主体内容区

#### 3.4.1 首页（品牌展示页）
- **区域一：英雄区**：地图轮廓淡影背景，大标题、副标题、搜索框、「开始探索」按钮
- **区域二：数据卡片区**：网格展示收录品种数、覆盖省份、畜禽类别、濒危保护品种等核心指标与更新时间
- **区域三：品种类别速览**：图标网格展示11个类别，点击直达百科对应分类
- **区域四：核心功能入口**：展示品种地图探索、品种百科、AI智能助手、图片识别功能入口卡片
- **区域五：最新收录品种**：轮播展示最新收录品种缩略卡片
- **区域六：关于本项目**：
  + 布局结构：两列等宽网格布局（移动端自动降级为单列）
  + 模块内容：包含项目简介、数据来源、技术平台、联系方式四个独立信息卡片
  + 样式规范：标题行强制等高（28px），采用金色(#d4a853)图标（20x20px）与半透明白正文排版，保持视觉垂直对齐

#### 3.4.2 品种地图页
- **地图组件**：展示全国各省份及畜禽点位，支持省份点击筛选与点位高亮放大
- **品种详情卡片**：展示品种中英文名、配图、省份、类别、濒危等级、体貌特征、五维生产性能雷达图（产肉/产奶/繁殖/役用/适应性）、文化故事，提供收藏、对比、分享操作

#### 3.4.3 数据看板页
- **统计图表**：各省品种数量条形图、各类别占比环形图、保护品种分布图、类别对比柱状图、省份密度热力图、濒危等级分布图，均支持数据导出（PNG/CSV）

#### 3.4.4 品种百科页
- **检索与筛选**：名称模糊搜索（300ms防抖）、类别/省份/濒危等级多维组合筛选
- **操作栏**：提供「导出数据」（CSV/Excel）与「随机探索」按钮
- **品种卡片列表**：卡片网格展示品种核心信息，支持分页与虚拟滚动，点击跳转至地图页联动定位

#### 3.4.5 AI助手页
- **容器布局**：整体高度固定为全屏视口自适应布局（calc(100vh - 56px)），采用纵向Flex排版，底部无多余空白
- **模式工具栏**：4个模式按钮（对话模式、生成报告模式、图片识别模式、生成图片模式）紧凑单行排列，选中状态展示墨绿色(#2d5016)，未选中状态为浅灰
- **推荐问题区**：缩减为单行3个高优先级推荐卡片（青海特色畜种、浙江猪品种、南方养牛推荐），横向等宽三列排列，支持点击快速填入输入框
- **对话流展示区**：占据主体剩余高度（flex-1 min-h-0，最小高度限制），支持独立滚动，气泡采用舒适内边距（24px 32px），支持错误提示与单条消息原地重试
- **输入控件区**：紧凑底部单行输入框（高度48px），发送/语音按钮（40x40px）居中对齐，控制外层边距保持紧凑
- **国际化（i18n）**：修复复制文本等国际化键值绑定，统一使用规范的命名空间，完整支持中英文双语切换
- **报告/图文扩展能力**：支持PDF报告生成、图片识别分类打分与概念图生成

#### 3.4.6 用户中心页
- **我的收藏**：展示已收藏品种卡片列表，支持单项取消与批量移除
- **个人信息**：查看与编辑用户昵称、头像
- **退出登录**：清除登录态并刷新视图

#### 3.4.7 品种对比页
- **对比列表**：支持2-4个品种横向并排对比（包含基本信息、体貌特征、五维雷达数据、文化故事），支持导出对比结果（CSV/Excel）

### 3.5 登录/注册页
- 支持手机号+验证码登录及账号密码登录
- 注册包含手机号、验证码、用户名、密码、协议勾选校验

### 3.6 底部页脚
- 展示版权信息与数据更新日志

## 4. 业务规则与核心逻辑

### 4.1 AI服务与对话交互逻辑
- **服务端健壮性**：
  + 跨域支持与请求上下文消息序列规范化校验（确保奇数长度、首尾角色为user）
  + 50秒请求超时中断机制（AbortController）及错误状态码标准化映射
- **前端交互与国际化规范**：
  + 对话区自适应撑满屏幕，无多余外边距；输入框、工具栏与推荐卡片固定高度
  + 文本复制、操作提示等国际化文本严格绑定多语言词条，禁止出现未定义键值报错

### 4.2 品种数据扩充与管理规范
- **数据来源与覆盖**：严格对照《国家级畜禽遗传资源保护名录》与《国家畜禽遗传资源品种名录（2024年版）》，持续扩充收录国家级保护品种与特色地方品种
- **第十五批扩充（extraBreeds14）规范**：
  + 查重校验：对未收录的地方特色品种、稀少类别及重点保护品种进行定向扩充
  + 字段规范：必须包含合法id、中英文名称、所属省份、地理坐标、类别、濒危等级、体貌特征、生产性能描述、五维雷达图完整数值、不少于100字的文化故事、独立真实配图
  + 注册与文档同步：在系统数据主入口完成批次注册，同步更新「docs/品种数据手册.md」、「docs/网站说明书.md」、「docs/品种图片索引.csv」并重新导出完整数据PDF文档

### 4.3 联动与筛选逻辑
- 左侧类别导航与百科筛选、地图点位高亮双向实时同步
- 百科多重筛选取交集，空数据展示占位与重置建议
- 地图点位选中保持高亮放大并同步高亮归属省份轮廓

### 4.4 用户数据存储规则
- 用户收藏夹、个人信息、对比列表持久化存储于后端数据库，未登录拦截并引导登录

## 5. 异常与边界情况

| 场景 | 处理方式 |
|------|----------|
| AI请求超过50秒或断网 | 中断请求并提示错误信息，对话框内保留重试按钮 |
| AI国际化词条缺失 | 回退至默认语言或通用文案，避免界面展示原始键名或抛出异常 |
| 首页在移动端视口下访问 | 「关于本项目」网格自适应调整为单列垂直排版，保持文字与图标对齐 |
| 搜索或多重筛选无结果 | 展示「未找到相关品种」并提供清空筛选/查看全部快捷按钮 |
| 品种图片加载失败 | 显示默认品种占位图 |
| 未登录用户触发收藏操作 | 弹出「请先登录」提示并引导至登录页 |
| 对比列表已满4个 | 提示「最多对比4个品种，请先移除部分品种」 |

## 6. 验收标准

1. 用户访问AI助手页，整体视图在不同分辨率下均撑满视口（calc(100vh - 56px)），推荐问题区以3列单行呈现，工具栏选中态显示墨绿色，单行48px输入框正常发送与重试，切换中英文时复制与操作提示文案正确生效且无i18n报错
2. 用户访问首页「关于本项目」区域，项目简介、数据来源、技术平台、联系方式4个卡片以两列等宽网格整齐对齐排列，标题行等高28px并配置金色图标，移动端自动呈现单列排版
3. 检查src/data/extraBreeds14数据文件与注册入口，确认第十五批特色与保护品种已完整录入，所有新增品种均包含完整字段、五维雷达图数据、不少于100字文化故事与独立真实配图
4. 检查docs目录，确认「docs/品种数据手册.md」、「docs/网站说明书.md」、「docs/品种图片索引.csv」均已同步更新第十五批品种数据，并成功重新生成PDF手册文档
5. 用户在品种地图页、品种百科页、数据看板页中检索并浏览第十五批新增品种，各页面地图点位联动、分类筛选、详情卡片与数据导出功能正常
