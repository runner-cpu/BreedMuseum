# 中国地方畜禽品种数字博物馆需求文档

版本：2026-09-28

## 1. 产品目标

建设一个无需登录即可使用的地方畜禽品种科普站，帮助公众和专业学习者检索、浏览、比较并追溯品种资料。产品必须明确区分馆藏记录、国家级保护名录身份和待核验的编辑信息。

## 2. 目标用户

- 动物科学、畜牧与相关专业学生和教师。
- 畜牧从业者与地方种质资源工作者。
- 对地方品种、农业文化和生物多样性感兴趣的公众。

## 3. 核心场景

- 按名称、英文名、别名、类别和省份找到品种。
- 在地图中理解近似地域分布并打开来源透明的详情。
- 通过数据看板读取统计，并以表格或文件导出。
- 将多个品种加入对比，识别共同点、差异和缺失数据。
- 在可选 AI 服务中提出问题；服务未配置时仍可使用全部公共内容。

## 4. 信息架构

| 页面 | 必需能力 |
| --- | --- |
| 首页 | 品牌、全站搜索、真实统计、核心入口和数据口径提示 |
| 地图 | 搜索、类别和省份筛选、近似点位、可分享详情 |
| 看板 | 类别、省份、名录与资料状态统计、表格摘要、CSV/PNG 导出 |
| 百科 | 完整结果列表、多条件筛选、别名与英文名检索 |
| 对比 | 空状态、加入与移除、文本和五维表格、CSV 导出 |
| AI | 配置检测、完整流式响应、取消、超时与安全错误文案 |
| 404 | 保留未知路径并提供恢复导航 |

当前产品不包含登录、注册、用户中心或云端收藏。对比状态仅服务于当前浏览体验。

## 5. 数据需求

- 运行时 ID 与名称必须唯一。
- 每条记录必须能解析到至少一个来源目录项。
- 第 940 号公告只用于名称与国家级保护名录身份匹配。
- “国家级保护名录”不得显示为“濒危”。
- 雷达数据只能是五项完整的 0–100 数值，或五项全部为空。
- 缺少指标证据的记录显示“待核验”和“性能指标待补充”。
- 历史图片未完成权利审查前必须标记“来源权利待核验”。
- 蜂和蚕在建立适用模型前不进入现有五维畜禽数据集。

## 6. 体验需求

- 桌面 1440×900 和移动 390×844 均能完成所有核心旅程。
- 移动端提供完整菜单、搜索、类别抽屉和可关闭的地图详情。
- 主要触控目标至少 44px；支持键盘焦点、跳到主内容和语义标题。
- 图表必须提供文本或表格替代；不能只靠颜色传递信息。
- 图片失败后保留容器尺寸并显示 SVG 占位，避免布局跳动。
- 页面不得出现文档级横向溢出。

## 7. 可靠性与安全

- 无后端配置时静态页面必须正常渲染。
- AI 流式请求上限 120 秒，用户取消不显示错误。
- 生产界面不显示异常堆栈或服务端响应正文。
- .env.production 不得纳入版本控制，公开示例文件不得包含真实密钥。
- CSV 导出防止公式注入并使用 UTF-8 BOM。
- 依赖审计、类型检查、代码检查、单元测试、构建预算和 E2E 纳入统一发布门禁。

## 8. 验收标准

- 数据审计无重复、无缺失来源、无非法枚举或混合空值雷达。
- 运行时总数、类别统计、文档和图片索引由同一生成器同步。
- 271 个公告畜禽名称全部匹配，站点不夸大为 701 个国家级保护品种。
- 新增名称证据记录不包含推测的濒危标签或雷达分值。
- 所有主路由、AI 未配置状态和真实 404 通过桌面与移动端 E2E。
- 生产依赖审计结果和剩余风险写入全面审计报告。

## 9. 非本期范围

- 用户账户、收藏同步、评论或社区。
- 交易、商业供应链、育种决策或兽医诊断。
- 品种 3D 模型与视频生成。
- 自动抓取并未经人工审核的外部数据。
- 在现有指标体系中强行加入蜂和蚕。
