隐私与 AI 使用说明

更新日期：2026-10-02

本站以静态公开资料为主体，不要求登录，也不建立用户画像。

AI 功能会发送什么

只有在主动使用 AI 问答、报告、语音识别、图片识别或图片生成时，输入内容才会经 Supabase Edge Functions 转发给部署方配置的第三方服务。请勿上传敏感或可识别个人信息。

用途、保存与删除

数据仅用于当前任务。项目本身不承诺第三方长期保存期限，也无法替第三方作出删除保证；浏览器不会把原始图片或录音写入项目数据库。

结果边界

AI 输出可能错误，不能替代动物防疫、育种、生产、投资或法律意见。请回到品种详情页核对来源。

图片来源与版权状态

本站品种照片按以下三类来源管理，每条记录的图片状态均可在品种详情页的“数据来源与核验”区查看：

1. 外链图片（约 668 条）：来自项目早期图像检索得到的历史第三方 CDN 链接。这些图片的作者与授权信息尚未完成核验，站内统一标注“图片来源待核验”，完整清单（含逐条来源状态）见公开索引 breed-images.csv。

2. 项目原创 SVG 占位图（19 条）：由本项目绘制的插画，版权归属项目所有。

3. 后续计划：将逐步把外链图片替换为可核验授权的开放许可图片（如 Wikimedia Commons 等来源）或项目自绘 SVG，并在此页同步更新授权清单。

若您是某张图片的权利人并希望移除或署名，请通过下方的 GitHub Issues 联系我们，确认后将在 7 日内处理。

纠错

请在 GitHub Issues 提交可公开核验的纠错信息，不要粘贴个人敏感信息。
